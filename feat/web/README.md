# ACM Forever Vue 前端

Vue 3 + Vue Router + Vite。社区、个人中心、训练工具及 9 个管理模块均由 Vue 组件渲染，通过原来的 `/api/*` 接口访问 Python 服务。

## 本地开发

需要 Node.js 22.13 或更新版本、pnpm 11.25.0。先按 [API README](../api/README.md) 启动后端，默认端口 `8088`，再在本目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5173/`。Vite 将 `/api`、`/uploads`、`/health` 代理到 `127.0.0.1:8088`；登录 Cookie 与 CSRF 请求走同源代理。使用 `127.0.0.1`，避免混用 `localhost` 导致 Cookie 不一致。

## 生产构建

```powershell
pnpm build
```

生成 `dist/`，Quart 在 `8088` 上提供构建后的页面与资源。未构建时页面返回 `503` 并提示构建；API 仍可单独使用。`pnpm preview` 仅预览静态制品，业务联调使用 Vite 开发代理或 Quart。

保留 `/index.html`、`/post.html?id=...`、`/compose.html?draft_id=...`、`/home.html`、`/leaderboard.html`、登录与改密路径，后台仍是 `/admin.html?section=...&tab=...`。旧管理入口与普通成员的训练、题库、赛事复盘链接也保留。

## 目录

- `src/views/`：社区与账户页面、后台壳及旧入口。
- `src/admin/`：成员账号、成员资料、训练、题库、CF 选题、赛事复盘、同步任务、审核、设置。
- `src/components/`：导航、主题编辑器、图谱、插图、话题卡片和分页。
- `src/lib/`：请求与会话、Markdown 消毒、主题色算法、头像压缩、后台状态。
- `vite.config.js`：开发代理、生产媒体复制与构建配置。

沿用 `api/acm_api/public/assets` 中的 CSS 与媒体。原生页面和业务脚本暂留在旧目录，供历史版本对照及现有单元用例使用；它们不打包、不提供为活动页面。主题算法与头像压缩以模块形式迁入 Vue，修改后需要同步维护相关算法的检查用例。

## 题库采集

Web 管理员和 Root 在 **管理后台 → 题库管理** 顶部使用 **初始化数据库** 和 **拉取题目**。初始化只补齐 SQLite 表结构并刷新平台统计，保留已有数据；不会自动启动采集。普通成员题库不显示这些管理操作，也不请求管理接口。

选择 AtCoder / Codeforces 后可按比赛 ID 和指定题号采集，或选择 **该平台全部题目**。全平台模式先导入公开目录，再自动分批采集所有待处理题面与样例；每批题数不是总题数上限。默认跳过成功采集的题目，失败内容和取消前已经入库的数据会保留。

页面显示目录导入、题面进度、失败原因，并可取消采集。离开页面时停止查询与轮询，后台采集继续；同次登录返回时通过 `/api/tasks` 恢复进度。提交确认独立于组件生命周期，返回页面会复用确认结果；退出或切换账号会清除本地任务缓存。服务重启后历史任务记录不保留，可再次发起采集以继续未完成题目。

入口组件为 `src/components/ProblemCollection.vue`，请求和恢复逻辑在 `src/lib/problem-collection.js`，`ProblemTaskProgress.vue` 同时用于题库和同步任务页。使用现有数据库、采集和任务 API，无需修改后端权限或数据库结构。

## 本地题目详情

管理员和成员题库中的 **打开题目** 均进入 `/problem.html?platform=...&problem_id=...`，读取 SQLite 中已采集的题面和样例。详情页的 **查看原题** 才会打开平台原始网址。目录已收录但题面尚未采集时，页面显示等待或失败提示，可点击 **重新检查**；查看题目本身不会启动采集。

`src/views/Problem.vue` 使用现有题目详情 API；成员请求自动映射到 `/api/me/problems/...`。`src/lib/problem-content.js` 通过 DOMPurify 过滤题面 HTML，限制图片来源，并使用 KaTeX MathML 渲染 CF / AtCoder 公式。优先在原题面样例位置显示保存的输入输出，保留空格与换行并支持复制；无法匹配位置时在正文后补充样例。

无样例题目仍显示已保存正文。PDF 题面在详情页内嵌预览，从本站读取 SQLite 中的原始文件，并保留 **打开已采集 PDF** 供单独阅读；原文件包含的图示、公式与样例按原文保留，暂不拆成可复制样例字段。查看原题依然使用独立按钮。

`PdfPreview.vue` 使用本地 PDF.js 绘制当前页，支持翻页、缩放和适应宽度；离页或切换题目时销毁加载任务及 Worker。渲染器按需加载，字体与字符映射资源由 Vite 打包到 `assets/pdfjs/`，无需浏览器内置 PDF 插件或外部 CDN。

## 状态与安全约定

- 所有页面加载在离开时取消，替代查询取消旧请求；定时轮询随模块销毁停止。
- 登录与角色检查同时保留在 Quart 和 Vue 路由，实际接口权限始终由后端校验。
- 页面实例按路径、登录状态和账号区分；退出或切换账号后重新加载页面数据，清除上一账号的点赞、收藏等状态。注销时受保护页面立即移除，避免匿名状态下重新挂载后台。
- 首次改密期间不读取管理员偏好；改密页收到 428 时显示接口错误，不重复跳转到自身。
- 管理后台沿用共享模块布局，搜索栏只在外框显示焦点提示，复选框保持固定尺寸；操作按钮统一高度并在窄屏换行。
- Markdown 仅通过 `marked` + DOMPurify 的允许列表渲染；用户资料与评论使用 Vue 文本插值。
- 账号临时密码仅保存在组件内存中，离开提醒、离开清除，导出 CSV 转义公式前缀。
- 批量发号跨页选择达到 20 人时保留已有名单，只跳过新增选择；取消勾选时才移除成员。角色下拉框显示服务器已确认的角色，更新失败时保留原值，成功后通过刷新列表显示新角色。
- CF 同步 POST 的提交确认不随模块卸载取消，重进模块继续读取任务；复制候选题前重新查重。
- CF 任务、候选输入和后台筛选缓存仅在同一次登录会话内保留。社区、后台和改密页统一退出清理；会话失效或重新登录也会重置。旧会话迟到的同步确认及组件卸载不能重新写入缓存。
- 草稿保存串行处理并保存后续编辑，离开路由前等待保存；刷新或关闭页面时，尚未开始保存的修改通过 keepalive 补存：新草稿 POST、已有草稿 PUT，复用同一保存队列并取消待执行的自动保存计时器。补存不触发路由跳转或草稿列表刷新，实际成功仍取决于浏览器请求与服务端响应。
- 主题兼容 `acm.theme.v1` 与 `acm.theme.library.v1`，同时比较基础色和高级覆盖色判断预设选中状态。

## 回归测试

```powershell
pnpm test
```

`tests/session-view.test.mjs` 使用 Vue 自带的 SFC 编译器和内存渲染器，挂载实际 App、Header、Forum、PostCard 及 Vue Router；主题编辑器和图形组件使用空占位。11 个用例覆盖同页退出、切换账号、退出失败、取消离开、401、延迟响应、匿名加载失败、受保护页面移除、重复导航、后台缓存清理和会话过期响应。

`tests/problem-collection.test.mjs` 挂载实际题库、采集表单和任务页，覆盖管理员入口、成员隔离、请求参数与 CSRF、初始化、取消、完成后刷新、离页恢复、迟到的提交确认和账号切换；采集请求使用模拟响应，不会访问 OJ 或改动本地题库。

`tests/problem-detail.test.mjs` 使用 jsdom 验证真实题面消毒、公式与样例 DOM，并挂载题库和详情组件验证站内链接、独立原题按钮、成员请求、未采集状态、样例复制以及迟到响应的处理。

这些组件测试使用模拟 HTTP 响应，不覆盖浏览器布局、Cookie 或关闭页面的 keepalive 行为。API 合约测试另用临时数据库及 Quart 测试客户端验证实际注销、账号切换后的列表与详情状态隔离；不修改本地开发数据库。

CI 先构建 Vue，再运行 API 合约、Vue 组件回归及原有脚本用例。部署工作流先构建再打包 `feat/`，包含 `web/dist`，排除依赖目录、缓存与本地数据库。旧原生脚本用例不代表 Vue 交互回归已通过；登录、草稿、批量发号、同步恢复等仍需在本地环境完成验收后再合并。
