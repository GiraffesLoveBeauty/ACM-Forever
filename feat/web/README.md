# ACM Forever Vue 前端

Vue 3 + Vue Router + Vite。社区、个人中心、训练工具及 9 个管理模块均由 Vue 组件渲染，通过原来的 `/api/*` 接口访问 Python 服务。

## 本地开发

### 社区设计模板

首页沿用社区介绍、讨论主栏、热门话题与社区公约的三栏结构。`src/phase-theme.css` 在共享样式之后加载，提供放射图盘、四色轨道、三角标记、深色侧栏和清晰的正文阅读区；图案由 CSS 绘制，不依赖生成效果图。`GraphArt.vue` 保留十二节点、最短路径和键盘点选，新增图形均不接收指针事件。

首次访问仍使用原有设计与原有默认配色。在页头“主题库”打开分类面板，从“明日方舟”分类选择“相变信号”，才启用新增的特殊设计。从“默认”分类选择“原有设计模板”立即恢复原外观。所有相变样式限定在 `data-design-template="phase"` 下，原模板中隐藏新增装饰。

主题库使用 `src/lib/design-template.js` 中的 `TEMPLATE_CATEGORIES` 和 `DESIGN_TEMPLATES` 登记分类及模板。分类包括“默认”“明日方舟”“原神”“绝区零”“我的世界”，没有模板的分类显示空状态。后续开发者先登记唯一分类 ID 与模板 ID、名称、介绍和预览类型，再提供以 `data-design-template` 隔离的样式以及 `templateTheme` 中的默认配色。模板 ID 必须稳定，独立存储键由该 ID 生成；原模板和相变信号已有存储键兼容保留。分类只管理展示归属，不会改变当前模板或配色；点击具体模板才应用。

主题库内置“制作与投稿说明”。个人配色 JSON 的编辑与导入、完整模板的登记示例、资源来源、可用性检查与源码 PR 投稿流程见 [theme-development.md（个人主题开发与投稿规范）](../../docs/theme-development.md)。

设计模板选择使用 `acm.design-template.v1` 保存。原模板继续使用 `acm.theme.v1` 与 `acm.theme.library.v1`；特殊模板独立使用 `acm.theme.phase.v1` 与 `acm.theme.phase.library.v1`。切换时恢复对应模板自己的配色、明暗模式和收藏方案，不会把上一套配色带到另一模板。特殊模板首次使用独立的黄绿信号配色。

“工业黄”“清绿”“白灰”等配色仍可在当前模板内选择；“恢复此模板原配色”预览当前模板默认颜色，点击“保存主题”确认，取消则撤销预览。“仅本页应用”在本次页面会话切换模板时保留，刷新后回到已保存配色。支持明暗模式及减少动态效果，窄屏优先显示讨论主栏。

主题验证使用独立的本地 API 数据库。预览数据库、脚本和截图放在根目录忽略的 `data/`，示例帖子不进入生产数据。可按下面的标准启动步骤运行自己的本地数据；不要为看效果连接生产数据库。

“主题库 → 明日方舟”还可选择独立的“天使之城”。`src/angel-city-theme.css` 与 `src/components/AngelCityArt.vue` 提供雾白底色、钴蓝坐标、原创尖拱建筑及镜像等高线、黑白分类标签和六边形热榜序号。参考用户提供的五张界面与宣传截图，实际渲染使用 CSS/SVG，无外部图片或字体依赖；全部样式限定在 `data-design-template="angel-city"` 下，装饰仅在选用时挂载，保留原来的图谱交互。

天使之城的默认浅色强调色为 `#155bd8`，深色为 `#74adff`；当前配色与收藏分别使用 `acm.theme.angel-city.v1` 与 `acm.theme.angel-city.library.v1`。可编辑、导入导出、收藏或恢复该模板默认色，原模板与相变信号的已保存方案不受影响。

“主题库 → 我的世界 → 方块工坊”启用完整的 `minecraft` 模板。`src/minecraft-theme.css` 提供石质物品槽、草地绿强调色、像素立体边框和按钮按压反馈，`src/components/MinecraftArt.vue` 绘制原创方块地形、树与工作台，图谱继续支持原有点选与键盘操作。浅深模式、共享面板、表单和窄屏布局均有对应样式，主题库与调色弹窗保持通用界面。

方块工坊使用灰色背包容器、凹陷物品槽、黑色输入框与原创泥土平铺背景。浅色强调色为 `#3c8527`，深色为 `#a2c881`；配色与收藏独立使用 `acm.theme.minecraft.v1` 和 `acm.theme.minecraft.library.v1`。已保存的旧版配色不会被覆盖，可在自助调色中“恢复此模板原配色”后保存。

`CommunityArt.vue` 在方块工坊中使用 `MinecraftPodium.vue` 的草地方块领奖台和 `MinecraftJourney.vue` 的工作台、像素镐探索小径；其他模板保持原插画。个人中心横幅使用可收缩网格，排行榜入口在窄屏换行，保持在面板内。社区介绍星标独立居中；首页、排行榜和后台搜索框采用外层中性焦点框，输入框不重复绘制绿色轮廓。

常用正文与控件采用 14px 像素字，首页“拆解问题。连接思路。”标题在桌面为 48px、窄屏为 36px。后台章节带有灰色面板，避免文字直接落在泥土背景上；点赞、收藏使用立体按钮，悬停或键盘聚焦时反色，减少动态效果偏好下取消位移。

参考 `nagatoquin33/astrbot_plugin_stealer`、中国版官网与 Minecraft-CSS 的视觉组织后独立实现，没有复制参考项目源码或游戏素材。中文像素字体采用本地提供的“缝合像素字体”`2026.10.25` 版，保留 OFL 和组合字形许可，无字体 CDN、音效或新增 npm 依赖。来源、哈希与许可见 [README.md（字体来源与许可）](src/assets/fonts/fusion-pixel/README.md)；完整配色与研究说明见 [theme-development.md（个人主题开发与投稿规范）](../../docs/theme-development.md#9-方块工坊模板)。

需要 Node.js 22.13 或更新版本、pnpm 11.25.0。先按 [API README](../api/README.md) 启动后端，默认端口 `8088`，再在本目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5173/`。Vite 将 `/api`、`/uploads`、`/health` 代理到 `127.0.0.1:8088`；登录 Cookie 与 CSRF 请求走同源代理。使用 `127.0.0.1`，避免混用 `localhost` 导致 Cookie 不一致。

## 生产构建

```powershell
pnpm build
```

生成 `dist/`，Quart 在 `8088` 上提供构建后的页面与资源。未构建时页面返回 `503` 并提示构建；API 仍可单独使用。`pnpm preview` 仅预览静态制品，业务联调使用 Vite 开发代理或 Quart。

保留 `/index.html`、`/post.html?id=...`、`/compose.html?draft_id=...`、`/home.html`、`/leaderboard.html`、登录与改密路径，后台仍是 `/admin.html?section=...&tab=...`。新增受保护的个人题库 `/my-problems.html`，供所有登录角色查看本人 AC。旧管理入口与普通成员的训练、题库、赛事复盘链接也保留。

## 目录

- `src/views/`：社区与账户页面、后台壳及旧入口。
- `src/admin/`：成员账号、成员资料、训练、题库、CF 选题、赛事复盘、同步任务、审核、设置。
- `src/components/`：导航、主题编辑器、图谱、插图、话题卡片和分页。
- `src/lib/`：请求与会话、Markdown 消毒、主题色算法、头像压缩、后台状态。
- `vite.config.js`：开发代理、生产媒体复制与构建配置。

沿用 `api/acm_api/public/assets` 中的 CSS 与媒体。原生页面和业务脚本暂留在旧目录，供历史版本对照及现有单元用例使用；它们不打包、不提供为活动页面。主题算法与头像压缩以模块形式迁入 Vue，修改后需要同步维护相关算法的检查用例。

## 题库采集

Web 管理员和 Root 在 **管理后台 → 题库管理** 顶部使用 **初始化数据库** 和 **拉取题目**。初始化只补齐 SQLite 表结构并刷新平台统计，保留已有数据；不会自动启动采集。普通成员题库不显示这些管理操作，也不请求管理接口。

主导航和个人中心的 **题库** 对所有登录角色统一进入独立 `/my-problems.html`，提供目录、本人已 AC、搜索、收藏及站内题面；不显示成员 QQ 选项，收藏仅操作登录账号本人。管理页按 **服务端数据库 → 拉取题目 → 题库记录** 排列，采集及初始化后刷新记录表并保留当前筛选与页码。

题库的 **比赛进度**（`/my-problems.html?view=tracker`）按比赛展示 Codeforces / AtCoder 已入库的题目，题序自然排序，包含 D1 / D2 等子题。题目列表和比赛进度的平台筛选均默认 Codeforces，不提供“全部平台”；清除筛选也恢复 Codeforces，显式选择 AtCoder 等平台时保留该选择。每格同时使用文字和底色标出 **已 AC / 尝试未通过 / 未记录**，显示难度和整场 AC 进度；横向滚动时固定比赛列。每页 20 场比赛，搜索、收藏和“我已 AC”用于选择比赛行，选中的比赛仍展示全部已收录题目。点击题目进入站内题面，返回保留视图、筛选和页码。

进度接口 `/api/me/problems/tracker` 只读取会话本人已同步的 AC 和提交尝试，不请求原站或启动采集。“未记录”不代表从未提交；各平台提交同步覆盖范围不同，查看前可先在个人中心检查绑定及同步状态。比赛未保存完整名称时显示平台和比赛 ID。实现见 `src/components/ProblemTracker.vue`，回归测试为 `tests/problem-tracker.test.mjs`。

仅有本人提交尝试、尚未进入目录的题目仍可打开站内详情：详情接口使用本人的尝试记录提供题号和原题链接，显示“题面尚未采集”，不返回源码、不自动抓取题面。已保存的题面和目录信息保持优先。

CF 离线导入的 `100A` 与服务端的 `cf_100A` 可通过同一比赛进度链接读取。详情和 PDF 接口兼容前缀及大小写别名，优先已保存的题面；仅有旧推荐或 AC 元数据时也能打开详情。原数据库题号保持不变。

选择 AtCoder / Codeforces 后可按比赛 ID 和指定题号采集，或选择 **该平台全部题目**。全平台模式先导入公开目录，再自动分批采集所有待处理题面与样例；每批题数不是总题数上限。默认跳过成功采集的题目，失败内容和取消前已经入库的数据会保留。

页面显示目录导入、题面进度、失败原因，并可取消采集。离开页面时停止查询与轮询，后台采集继续；同次登录返回时通过 `/api/tasks` 恢复进度。提交确认独立于组件生命周期，返回页面会复用确认结果；退出或切换账号会清除本地任务缓存。服务重启后历史任务记录不保留，可再次发起采集以继续未完成题目。

入口组件为 `src/components/ProblemCollection.vue`，请求和恢复逻辑在 `src/lib/problem-collection.js`，`ProblemTaskProgress.vue` 同时用于题库和同步任务页。使用现有数据库、采集和任务 API，无需修改后端权限或数据库结构。

## 本地题目详情

管理员和成员题库中的 **打开题目** 均进入 `/problem.html?platform=...&problem_id=...`，读取 SQLite 中已采集的题面和样例。详情页的 **查看原题** 才会打开平台原始网址。目录已收录但题面尚未采集时，页面显示等待或失败提示，可点击 **重新检查**；查看题目本身不会启动采集。

`src/views/Problem.vue` 使用现有题目详情 API；成员请求自动映射到 `/api/me/problems/...`。`src/lib/problem-content.js` 通过 DOMPurify 过滤题面 HTML，限制图片来源，并使用 KaTeX MathML 渲染 CF / AtCoder 公式。优先在原题面样例位置显示保存的输入输出，保留空格与换行并支持复制；无法匹配位置时在正文后补充样例。

无样例题目仍显示已保存正文。PDF 题面在详情页内嵌预览，从本站读取 SQLite 中的原始文件，并保留 **打开已采集 PDF** 供单独阅读；原文件包含的图示、公式与样例按原文保留，暂不拆成可复制样例字段。查看原题依然使用独立按钮。

`PdfPreview.vue` 使用本地 PDF.js 绘制当前页，支持翻页、缩放和适应宽度；离页或切换题目时销毁加载任务及 Worker。渲染器按需加载，字体与字符映射资源由 Vite 打包到 `assets/pdfjs/`，无需浏览器内置 PDF 插件或外部 CDN。

## 状态与安全约定

- 所有页面加载在离开时取消，替代查询取消旧请求；定时轮询随模块销毁停止。
- 登录与角色检查同时保留在 Quart 和 Vue 路由，实际接口权限始终由后端校验。
- 页面实例按路径、登录状态和账号区分；退出或切换账号后重新加载页面数据，清除上一账号的点赞、收藏等状态。注销时受保护页面立即移除，避免匿名状态下重新挂载后台。
- 首次改密期间不读取管理员偏好；改密页收到 428 时显示接口错误，不重复跳转到自身。
- 管理后台沿用共享模块布局，搜索栏只在外框显示焦点提示，复选框保持固定尺寸；操作按钮统一高度并在窄屏换行。
- Markdown 仅通过 `marked` + DOMPurify 的允许列表渲染；用户资料与评论使用 Vue 文本插值。
- 帖子支持列表 / 网格切换：列表中摘要与封面并排，网格中封面位于卡片上方，无封面的帖子展示分类占位图；列数随可用宽度调整。默认列表，本浏览器记住视图选择；切换保留筛选、排序、加载页及互动状态，不重新请求帖子。详情按标题、作者、大封面、正文展开，并保留右侧目录；窄屏自动堆叠。写帖支持编辑 / 双栏 / 预览，封面选填，正文支持选择、粘贴或拖入 PNG/JPEG/WebP。最大 20 MB 原图先在浏览器缩放、压缩，再通过登录与 CSRF 校验上传；封面和正文随账号草稿一起保存、恢复和提交审核。
- Markdown 仅展示本站 `/api/forum/images/<id>` 和 `/api/markdown/assets/<id>` 管理的图片，外部或内嵌图片显示替代文字；导入 `.md` 不会自动导入相对路径图片，需另行上传。上传期间禁止切换草稿或离开编辑路由，失败保留已编辑内容并显示原因。单篇最多 30 张图片，服务器存储与备份说明见 [API 指南](../../docs/api.md#帖子封面与正文图片)。
- 账号临时密码仅保存在组件内存中，离开提醒、离开清除，导出 CSV 转义公式前缀。
- 批量发号跨页选择达到 20 人时保留已有名单，只跳过新增选择；取消勾选时才移除成员。角色下拉框显示服务器已确认的角色，更新失败时保留原值，成功后通过刷新列表显示新角色。
- CF 同步 POST 的提交确认不随模块卸载取消，重进模块继续读取任务；复制候选题前重新查重。
- CF 任务、候选输入和后台筛选缓存仅在同一次登录会话内保留。社区、后台和改密页统一退出清理；会话失效或重新登录也会重置。旧会话迟到的同步确认及组件卸载不能重新写入缓存。
- 草稿保存串行处理并保存后续编辑，离开路由前等待保存；刷新或关闭页面时，尚未开始保存的修改通过 keepalive 补存：新草稿 POST、已有草稿 PUT，复用同一保存队列并取消待执行的自动保存计时器。补存不触发路由跳转或草稿列表刷新，实际成功仍取决于浏览器请求与服务端响应。
- 主题兼容 `acm.theme.v1` 与 `acm.theme.library.v1`，同时比较基础色和高级覆盖色判断预设选中状态。

## 入口与访问恢复

公开页面和登录表单先显示，会话在后台确认；个人中心、编辑器和管理页面仍等待认证，认证失败进入可重试的恢复页。首次改密继续保留原目标。页头登录、会话过期及旧管理入口跳转会保留查询参数与锚点，登录和恢复页不能作为登录后的循环返回目标。

页面模块下载失败时显示“页面加载失败”，保留当前页面及输入；可以继续当前页面，或重新加载目标地址获取最新资源。取消或失败的离开操作会恢复论坛编辑器的正常保存和草稿地址更新。直接打开无权限页面仍返回 HTTP 403，由同一 Vue 外壳显示提示；未知页面使用统一的不存在提示并返回 404，API 与资源地址不进入页面回退。

`tests/access-navigation.test.mjs` 验证慢认证、登录返回、首次改密、会话过期、旧入口锚点及模块加载恢复；`tests/compose-navigation.test.mjs` 补充编辑器在导航失败与取消后的保存回归。后端对应入口契约见 `feat/api/tests/test_web_access.py`。

## 回归测试

```powershell
pnpm test
```

`tests/session-view.test.mjs` 使用 Vue 自带的 SFC 编译器和内存渲染器，挂载实际 App、Header、Forum、PostCard 及 Vue Router；主题编辑器和图形组件使用空占位。11 个用例覆盖同页退出、切换账号、退出失败、取消离开、401、延迟响应、匿名加载失败、受保护页面移除、重复导航、后台缓存清理和会话过期响应。

`tests/problem-collection.test.mjs` 挂载实际题库、采集表单和任务页，覆盖管理员入口、成员隔离、请求参数与 CSRF、初始化、取消、完成后刷新、离页恢复、迟到的提交确认和账号切换；采集请求使用模拟响应，不会访问 OJ 或改动本地题库。

`tests/problem-detail.test.mjs` 使用 jsdom 验证真实题面消毒、公式与样例 DOM，并挂载题库和详情组件验证站内链接、独立原题按钮、成员请求、未采集状态、样例复制以及迟到响应的处理。

这些组件测试使用模拟 HTTP 响应，不覆盖浏览器布局、Cookie 或关闭页面的 keepalive 行为。API 合约测试另用临时数据库及 Quart 测试客户端验证实际注销、账号切换后的列表与详情状态隔离；不修改本地开发数据库。

CI 先构建 Vue，再运行 API 合约、Vue 组件回归及原有脚本用例。部署工作流先构建再打包 `feat/`，包含 `web/dist`，排除依赖目录、缓存与本地数据库。旧原生脚本用例不代表 Vue 交互回归已通过；登录、草稿、批量发号、同步恢复等仍需在本地环境完成验收后再合并。

## 普通成员训练页面

个人中心展示资料加载 / 失败 / 重试、本人 OJ 绑定与同步状态、最近 AC 和“查看全部已 AC”。最近 AC 进入站内 HTML / PDF 题面；“查看全部”统一指向 `/my-problems.html?scope=solved`，member / admin / root 均读取本人列表。个人题库使用独立 `MemberProblems` 页面，筛选、范围切换和分页沿当前个人地址更新，题面返回保留实际入口及允许的参数，不复用管理缓存。旧 `/problem-bank.html` 对普通成员仍可用，对 admin / root 仍进入后台。认证失败保留目标并显示重试；恢复页跳过自动初始化，超时后不再等待第二次认证，点击重试才重新请求。首次改密继续沿用原目标参数。

`OjBindings` 实现 CF 归属验证、当前 Web 密码及明确确认后的改绑 / 解绑、本人平台同步。密码仅短暂保存在组件中，请求完成、失败、取消或退出组件后清除。平台的 `self_service` 由后端决定，其他平台保留查看及管理员代操作提示。同步轮询在离开个人中心时停止，后台任务继续运行。平台开放与 API 契约见 [API 指南](../../docs/api.md#普通成员训练闭环)。

`tests/member-training.test.mjs` 挂载实际个人中心、个人题库、题面、绑定组件和实际路由守卫，覆盖未知统计、错误重试、本人筛选、往返上下文、安全返回、认证恢复与取消时清除密码。认证超时保留实际 API 的 AbortSignal 行为，用虚拟计时推进 15 秒并断言首次反馈前只有一次请求；直接打开恢复页应为零次。三种角色分别验证个人中心到本人列表、分页 / 收藏 / 返回及旧管理入口。真实 Cookie、真实超时、PDF 渲染和手机布局另用独立合成数据环境验收；预览、截图与演示数据库不进入仓库。

## Wiki 知识手册

主导航新增 `/wiki.html`，按大类→小类→文章浏览；查询参数承载分类、稳定 slug、搜索与分页，正文目录使用 hash。admin/root 在 `/admin.html?section=wiki&tab=categories|pages` 维护，沿用现有后台外壳。

`MarkdownEditor/MarkdownView` 复用源文本、净化与公式能力；论坛 Compose 保留原草稿恢复和审核流程，并接入帖子封面、双栏预览和论坛图片压缩上传（Wiki 仍使用共享图片接口）。共享编辑器支持 UTF-8 MD 导入、图片选择/拖拽/粘贴及失败重试；受控图片只加载本站资源。Wiki 草稿使用串行保存、离开保护、账号/文章隔离的本地恢复；409 保留输入并显式合并。`wiki.css` 沿用原有设计、相变信号、天使之城三套模板的主题变量，窄屏分类与目录可展开。

`tests/wiki.test.mjs` 在 jsdom 中挂载实际组件和路由，包含导入/渲染、上传取消、迟到搜索响应、保存期间继续编辑、冲突保留及离开新草稿后目标地址不丢失等回归。Cookie、真实文件下载和布局另用外部合成数据预览验收。API、图片持久化、运维与备份见 [Wiki 文档](../../docs/wiki.md)。
