# Android v0.2.16：全局搜索、便捷管理与自站更新

2026-11-05。基于 main `f30cf10`，本地实现与验证完成，待跨人评审。版本 `0.2.16` / `versionCode 30` / debug，包名及固定调试签名不变。上传前同步 #98 的题号去重修复；App源码和制品不受影响。本轮不修改 `feat/web`、`feat/api`、数据库或网站同步工作流。

## 用户可见变化

- 顶部搜索独立成全局搜索页，默认用户、论坛、Wiki、题目四项；结果按设置优先级两列排列，每模块独立分页。搜索设置位于账号设置的“账号与应用”，支持长按三条杠拖动、移除和重新添加模块。
- 历史记录可查询、删除、清空、停用，仅在本机保存最近10条。本人话题/收藏/草稿可添加为搜索模块，局限于原接口返回的最近100条；题单/按题讨论/错题没有搜索接口时显示“无API接口”。用户搜索包含零AC成员，但不改变正式排行榜排除零AC的规则。
- 管理员账号增加原生便捷管理：话题审核/退回、举报处理、任务查询/取消、成员查询、单题训练/历史、指定成员复盘和比赛播报。批量账号/权限/复杂编辑仍到网页；重新进入验证角色，管理数据不进入普通读取缓存。
- 清单与APK自站优先，GitHub备用。自动检查默认开，仍需点击确认下载，系统确认安装；所有源失败、取消、旋转/进程恢复继续处理。更新说明离线保存在APK中。
- Tag Action增加镜像事务：草稿三件制品回读、自站版本目录上传和公网回读、公开Release后原子提升latest；不能降级或覆盖已公开版本。

## 接口与配置说明

复用现有业务API，没有增加数据库访问或后端路由。公开资料及论坛通过服务器能力选择带稳定公开ID的移动接口；不把QQ或昵称当公开ID。

完整关联、接口/缺失列表与修改边界见 [android-modification-standard.md](android-modification-standard.md)。自站HTTPS地址、专用SSH、Nginx配置、Variables/Secrets、发布恢复步骤见 [android-self-hosted-release-v0.2.16.md](android-self-hosted-release-v0.2.16.md)。

网站域名已核对可访问，但拟用下载清单尚为404。本轮没有配置生产SSH、静态目录或Nginx；PR源码通过后仍需运维完成这些条件，才可创建Tag发版。
