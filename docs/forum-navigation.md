# 论坛列表状态

论坛列表将排序、版块、关键词、页码和网格/列表视图写入 URL，例如：

```text
/index.html?category=help&q=图论&page=2&view=grid
```

刷新、复制链接或使用浏览器前进/后退都能恢复这些条件。列表每页 12 条，切换排序、版块或关键词会回到第 1 页；切换网格/列表保留当前页。旧链接未指定视图时仍读取本地偏好。筛选结果变少导致页码越界时，自动校正到最后一页。

点击标题、摘要、封面、评论入口或热门话题时，会携带列表返回地址。详情「返回论坛」恢复原条件，当前标签页内也会恢复离开列表前的滚动位置。分页或筛选变化时，在旧列表清空前保存其位置；使用浏览器前进 / 后退时，等目标列表渲染完成后再恢复，避免慢请求导致位置被短页面高度截断。列表顶部的零位置也会保存和恢复。新标签页可通过链接恢复筛选条件，滚动位置取该标签页的会话存储；浏览器禁止存储时列表仍可正常使用。返回地址只允许站内论坛列表，不接受外部或管理页面。

加载失败提供重试；请求切换时取消旧列表加载，避免过时内容覆盖新结果。

验证：在 `feat/web` 运行 `pnpm test`、`pnpm build`。组件回归覆盖共享链接、分页与后退、切换排序/视图、越界页校正及故障重试；本地浏览器检查刷新、详情返回、评论入口和滚动恢复。
