## Review 重点和限制

1. `local_demo/server.py` 仅回环地址、本地 SQLite，停用同步后台与周期任务；不是生产后端注册入口。前端扩展接口在正式服务中尚不可用，合入部署前需约定能力开关、正式鉴权与持久数据挂载。
2. admin/root + CSRF + 同源校验、单题确认，配置只读取当前仓库独立 `.env`，不允许浏览器提供地址、模型或强制重试参数。
3. 新请求为 `layout_by_id`：本地保留规范化正文结构、原图、公式及代码样例，只翻译带 ID 的文字，回填时检查 ID 完整性。图片内文字不翻译，译文仍是「自动、未人工确认」。旧 `parse_only` 结果继续展示，不自动重翻。此前严格内容校验按用户要求退出自动路径，历史显式离线审计仍保留。详细边界见 [翻译协议](../experiments/tags/ACM_Forever_Chinese_Tags_V0.3/README_TRANSLATION_VALIDATION.md)。
4. 含关键信息的图片、PDF、未展开样例 ZIP 仍需补充可靠正文，不能把下载链接当正文。第三方题面及译文的共享许可需团队另行确认。
5. 上游未确认提供服务端幂等键，本地锁及 uncertain 状态不能绝对保证远程只计费一次；不得人工清除状态后盲目重发。服务商价格未知，账单为准。
6. 暂不迁移正式数据库、不自动搬入私人预测结果，不在此 PR 内执行付费翻译或标注。

建议先 review 本地验收与安全边界，确认正式后端接入方式后再由团队负责人决定合并。此分支不自行合并主线。
