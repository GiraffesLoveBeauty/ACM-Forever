## 行为变化

目标流程：登录 → 个人中心 → 查看或绑定 OJ 账号 → 查看本人已 AC 题目 → 打开站内题面 → 返回原页面。

- 认证初始化失败会显示可重试的恢复页并保留原目标。普通成员访问后台，直链返回 403，客户端显示无权限说明；原有管理员模块、登录与首次改密参数继续保留。
- 个人中心区分加载、错误与真实空数据，统计未知时显示占位；显示绑定 / 同步状态，最近 AC 进入站内题面，“查看全部”进入本人已 AC。
- 成员题库独立于后台组件与缓存。筛选、范围与页码放在地址参数中，HTML / PDF 题面返回时保留允许的来源和列表条件。
- `/api/me/problems?scope=solved` 仅使用会话 QQ，按平台和题号去重，按 AC 时间倒序及平台 / 题号稳定排序；默认 20、上限 100。原全站目录含义保持不变。
- Web 绑定完成服务端存在性和归属验证，验证有效期、限频、账号占用与并发校验。改绑 / 解绑需当前 Web 密码与明确确认；密码不缓存，失败保留原绑定。
- 当前网页归属验证实现 Codeforces 结构化公开资料字段；其他平台保留查看、同步、确认解绑和管理员代操作提示。真实平台验证通过后才应扩大开放范围。
- Web 与机器人复用平台映射、绑定写入和平台证据清理；所有平台有持久绑定版本。同步批次、同步状态、全员同步时间均校验版本，拦截解绑后重绑同名账号的旧任务。旧任务不会显示为新账号正在同步。
- 绑定提交与同步调度分别反馈，排队失败不撤销已成功绑定；管理员修改绑定需确认账号及版本，并记录成功与确认失败的操作结果。

接口参数和错误码见 [api.md（API 调用指南）](api.md#普通成员训练闭环)。本次不扩展完整训练推荐系统，不恢复待复习、提交时间线、笔记与计划。

## 数据迁移与恢复

启动 / `api.init_db` 增量添加：四个平台绑定版本列（CF 沿用原列）、验证标识 / 预期绑定 / 版本 / 存在性完成时间、`binding_rate_limits`、`binding_audit`、查询索引及绑定变化触发器。版本保存于 `users`，不会随同步状态清理重置。初始化可重复执行；旧验证没有网页验证标识，须重新申请网页验证，机器人内部确认流程仍受原有鉴权保护。

解绑 / 成功改绑仅清理目标成员、目标平台的 `submissions`、`submission_attempts`、`user_platform_sync_state`，并将活动挑战设为 abandoned。收藏及笔记、复习、计划历史存档不删除，其他平台和成员不受影响。

发布前由运维停止旧写入者，制作含 WAL 状态的可恢复备份，并在副本上重复初始化、核对数据量及核心流程。恢复时停止写入并保存故障现场，恢复已验收的数据库备份和对应源码，再核对绑定 / 同步 / 收藏及登录。新版本已执行过的证据清理不能靠回退代码复原。
