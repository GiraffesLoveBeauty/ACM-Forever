## 实施范围

目标流程：登录 → 个人中心 → 查看或绑定 OJ 账号 → 查看本人已 AC 题目 → 打开站内题面 → 返回原页面。

1. 入口与身份：复现个人中心、成员题库的入口问题，修复认证失败后的无反馈；保持登录、首次改密、直链与刷新行为一致。成员题库使用成员标题与独立筛选状态。
2. 本人记录与题面：扩展 `/api/me/problems?scope=solved`，以登录会话确定本人，按平台和题号去重、稳定排序和分页；个人中心及题库进入已有站内题面，返回保留允许的筛选参数和页码。
3. 绑定与同步：提取 Web 与机器人共用的绑定服务；实现归属验证、首次绑定、确认当前密码后的解绑和改绑。加入验证有效期、限频、并发校验和绑定版本保护，失败保留原绑定，旧任务不能写入新绑定的数据。
4. 状态与边界：区分加载、失败、空记录、未绑定与同步状态；普通成员不能读取他人私有数据或调用管理操作；保留已下线功能和历史存档的数据边界。

绑定接口、平台开放条件及清理范围在对应实现中记录；如需增量迁移，同时记录兼容、备份与恢复要求。不得把模拟 OJ 测试写为真实平台联测通过。
