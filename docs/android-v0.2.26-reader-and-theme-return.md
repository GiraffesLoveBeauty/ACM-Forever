# Android v0.2.26：论坛预览、公式、主题返回与搜索拖动

日期：2026-11-09。基线为已发布 v0.2.25/code39，main `800b71a1190d1d545412c652440af4e10ab9cfd7`。源码评审候选 v0.2.26/code40，分支 `codex/android-v0.2.26-markdown-math`。本轮按用户授权提交源码PR供跨人评审；未合并、创建Tag或发布。

## 修复范围

### 首页论坛三行摘要

用户明确选择与网页一致的三行纯文字摘要。此前首页直接显示接口 `excerpt` 中的原始 Markdown，未执行网页 `feat/web/src/lib/post-images.js` 的 `postExcerpt` 清理。

新增原生 `ForumExcerpt`，复用同样的规则：图片与被420字截断的图片尾部不露出，链接保留标签，去掉标题、强调、引用、代码等格式符号，合并换行和空白。首页与“我的话题/话题收藏/草稿”共用这一处理；继续用原生 TextView 限制三行并在末尾省略，不增加列表 WebView、网络请求或图片加载。没有摘要文字时不显示空白摘要行。

这里的“纯文字”与网页规则一致，不在卡片中渲染 TeX、HTML 或完整 Markdown；公式的正常排版在话题详情及预览阅读器中查看，不修改网页自身规则。

### Markdown 公式显示为源代码

原来的阅读器先运行 Markdown，再扫描公式。Markdown 会消耗 `\(...\)`、`\[...\]` 的反斜杠，处理公式里的下划线，或将带空行的公式拆成几个段落，导致 KaTeX 拿不到原文。

`reader/content.js` 现在通过 Marked 的块级和行内扩展，在 Markdown 处理前保留完整公式，再对这些节点运行原有 KaTeX。支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`，保留 Codeforces 三/六美元符号兼容。嵌入 Markdown 的 HTML 块仍保留原有公式能力。未闭合分隔符继续作为普通正文处理。

代码片段、代码块和转义的美元符号不参与转换。HTML 清洗名单、HTTPS 链接限制、KaTeX `trust:false` 及展开限制不变；没有新增 JavaScript 应用桥、CDN、网络请求或公式库依赖。论坛正文、发帖预览、评论及预览共用该阅读器；Wiki 和题面也须联查。

### 我的主题 → 设置 → 返回丢失位置

`AdvancedAppearanceActivity.onResume` 原来无条件重建页面，新 ScrollView 从顶部开始；内部页面栈也只记页面名，不记滚动位置。

现在保存每个个性化页面的独立滚动位置，返回时在布局完成后恢复，并随 Activity 状态保存。首次 `onResume` 不再重复重建，防止覆盖待恢复的位置。从主题编辑页返回仍刷新名称、缩略图和颜色；并未为了保留位置放弃读取修改。调色盘按主色、辅色及背景区分位置。内容删除导致页面变短时，由 ScrollView 将位置限制在现有内容范围。

### 搜索设置拖动边缘滚动

按用户要求，`ModuleEdgeScroll` 最大速度由96改为192dp/秒，同样的边缘深度和停留时长下速度曲线加倍，实际像素位移仍按屏幕密度换算。保留原有0.12秒渐进加速、按时间积分、掉帧步长限制、离开边缘立即停止，以及拖动碰撞和列表上下边界。历史0.2.21文档的96dp/秒是当时的记录，不回写修改。
