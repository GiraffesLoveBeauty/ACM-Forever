# Android v0.2.23：图片恢复、存储管理与帮助说明

状态：2026-11-07，待其他成员 Review；尚未合并、创建 Tag 或发布 APK。基于 main `3b73bb60`，版本号为 **0.2.23 / versionCode 37**，签名与渠道规则沿用现有 0.2.x debug。

图片预览支持原页重试和持续重连；连接问题按既有十秒失败提示处理，关闭提示仍重试，连接恢复后绿色提示三秒消失。格式、尺寸、体积、权限等错误不会自动循环。

账号设置中依次为：修改密码 → 存储管理 → 帮助与说明 → 检查更新。存储管理分缓存占用、临时清理、安装包管理三块；仅按白名单清理，保护账号、主题、草稿、活动阅读文件和近期分享。帮助统一引导至 QQ 群，并补数据与权限说明。

## 本地独立 Review 修复

针对 `e993721b` 的独立审查指出两条 P2：目录枚举失败被当作空目录；PDF 删除失败后丢失索引并误报清理成功。本轮修复这两条路径：不存在的可选目录仍可跳过，已有目录读取失败向上报告；主动清理 PDF 时仅移除已删除或已经不存在的缓存索引，失败项保留供手动重试。普通退出仍丢弃全部 PDF 索引，不因清理失败保留账号访问入口。

新增十项 JVM 回归，覆盖读取失败、缺失目录、非目录路径、PDF 部分失败/重试及退出行为；仪器用例增加页面显示失败后再次清理的验证。修复版已通过 Debug 主包与测试包构建、184 项 JVM 测试及 42 项 Python 检查，另 1 项 Windows 符号链接测试跳过；Lint 零错误、57 条既有警告。API35 的 `recoverysettings`、`startupupdates`、`creditslogin` 三组修复后回归均通过。详细验证与测试同步修正见[本地修改记录](android-recovery-storage-help-local-2026-11-07.md)。新 head 仍须复查，不将本地修复或机器人连接提示当成评审通过。
