# Android v0.2.18：搜索、官方主题适配与私人主题分享

状态：2026-11-05，本地候选版 `0.2.18` / versionCode `32`，待跨人 review。基于合并 #104 后的 main `36c1b8b9` 独立开发；本轮不合并、不建 Tag、不发布 APK。

## 修改范围

1. 搜索页只保留顶部的“搜索设置”，历史卡片保留“历史记录”。结果按设置的模块优先级单列展示；各模块分页、历史记录开关、十条上限、缓存和失败隔离不变。
2. 官方主题的原始 Vue/CSS/SVG 继续离线直接读取。之前桌面和移动 CSS 里的 195/230px 图谱高度、负位移、外层最小尺寸会覆盖手机的 112dp 容器，造成偏移、裁切和装饰比例不一致。现在整个原始场景在 400×300 画布排版后等比缩放，图谱填满设计画布，节点命中区域同步变换；不重新绘制图案。
3. 横幅文字和图谱使用独立的左右列、按可用宽度分配并垂直居中，不再固定占用140dp挤压文字。首页与私人主题预览共用 `HomeBanner`。
4. 原生网页主题的文字、横幅前景、强调色前景、选中背景/文字等派生值改为网页同一算法；保留六类显式覆盖，选中控件使用与前景匹配的浅强调背景。`ACMForever` 原生主题保持自己的配色规则，工业黄继续固化ID相关默认值。
5. 我的主题 → 设置中的“导出”改为“分享”，位置仍在重命名和删除之间。点击后后台生成完整 `.acmtheme`，调用系统分享面板，支持由用户选择已安装且接受文件的 QQ、微信等应用。文件格式、原图字节、裁剪坐标及完整配置保持兼容。

网页、业务后端、更新源与发布工作流均不修改；自站更新 #105 继续等待管理员配置，与本PR独立。

## 分享文件与权限

`ThemeShareProvider` 独立于 APK 更新的 Provider，`exported=false`。只允许读取缓存子目录中随机ID对应的 `.acmtheme`，通过系统 `ACTION_SEND` / `ClipData` 临时授予指定附件的读取权限。拒绝写入、修改、删除以及目录穿越；不允许读取账号设置或安装包。主题包继续只含白名单外观字段。

文件生成完成、关闭后才打开分享面板，重复点击不会打开多个面板。文件名保留主题名；内部使用随机ID防止重名覆盖。再次分享时清理七天前的自有缓存附件，系统也可能提前回收缓存，失效后重新分享即可。分享不改当前主题，不向业务服务器上传，不自动向好友发送消息。QQ/微信是否显示以及如何发送取决于其版本和文件接收能力，本轮不接入社交SDK或发送消息。

## 官方主题的采用边界

相变信号、天使之城、方块工坊以及原有模板均核对浅深模式，原图形和交互不替换为截图。网页 CSS 直接用于背景和图谱主题层；原生 Android 控件通过共享样式接收等价颜色。网页特有三栏布局、CSS 悬停和所有DOM按钮效果不会自动覆盖原生控件。离线模板仍是受审源码快照，网页主题更新后需重新构建和 review。

对照色数据由 `node Android_APP/tools/generate_web_theme_color_cases.mjs` 调用真实网页 `deriveTokens` 生成，覆盖官方/基础主题、浅深两态、保留或清空覆盖字段共32种情况。`WebThemeColorsTest` 对比11类实际派生色，避免只测试相同 Java 实现的副本。源JS变化后应重新生成对照数据并重建 renderer。
