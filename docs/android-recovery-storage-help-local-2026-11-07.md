# 图片故障恢复、存储管理与帮助说明（本地修改）

日期：2026-11-07。v0.2.23 / versionCode 37 候选，基于已发布 v0.2.22；待跨人 Review，未合并或发布。只上传源码 PR，不修改服务器或公开新安装包。后期范围另见[后期更新计划](android-follow-up-plan-2026-11-07.md)。

## 设置入口

账号设置 → 账号与应用中的顺序为：**修改密码 → 存储管理 → 帮助与说明 → 检查更新**。两页共用原有页面壳、主题、返回动画及强制登录限制，普通账号与管理员均可使用，不依赖新 API。

帮助与说明包含：

- “统一帮助、问题反馈”，正文严格使用“统一帮助与问题反馈在QQ群里直接提”。不填写未知群号，不自动发送消息。
- “数据与权限说明”，解释本机加密凭据、搜索/外观数据、服务器数据、清理与卸载区别，以及网络、通知、开机提醒恢复、图片选择和系统确认安装的使用方式。

## 存储管理的三张卡片

1. **缓存占用查看**：后台统计内容缓存的数据大小估计值、应用临时目录和下载目录，支持重新查看。内容数据字节不等于整个 Java 堆或 App 总内存；临时目录含已校验安装包。
2. **清理临时文件**：确认后清理进程内读取缓存、缓存 PDF 和超过 7 天的主题分享副本。使用白名单和路径校验；正在阅读的 PDF 工作副本与近期分享附件保留。账号密码、会话、搜索设置、主题原图、本机主题、草稿和安装包不受此操作影响。
3. **已下载安装包**：进入原更新页管理，进入时不自动联网检查；可查看已有状态、安装新版或确认清理本 App 下载的安装包。删除操作在后台进行，下载/校验/安装进行时拒绝清理；不卸载当前 App。版本来源、摘要、包名、签名校验继续沿用现有流程。

本机磁盘统计不把 `files/`、SharedPreferences 或 Keystore 当临时目录，不递归删除整个应用目录。外部收到但不属于本 App 下载命名规则的文件不会被安装包清理操作删除。

## 图片故障恢复

`ImagePreviewActivity` 增加原页“重新读取图片”，接入共享 `PageRefresh`：慢读取十秒显示红色“API连接失败”，明确连接失败且无缓存时立即反馈，十秒间隔自动重试；用户关闭提示不停止重试；恢复后绿色“重连成功”显示三秒自动消失。

格式、尺寸、体积不支持、权限拒绝与内容不存在不会自动循环重试，可由用户主动重新读取。新增媒体格式异常类型，避免将格式错误误报为无法连接服务器。退出页面或会话变化时不再把迟到结果绘制到旧页面，不重放任何写请求。

关联入口：`ImagePreviewActivity`、`PageRefresh`、`ApiClient`、`FailureState`、`StorageActivity`、`TemporaryStorage`、`PdfFiles`、`HelpActivity`、`AppUpdates`、`UpdateActivity`、`MainActivity` 和 Manifest。
