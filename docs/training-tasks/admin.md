# 后台训练任务使用与路由

状态：#121 实现，依赖 #119/#120；替换 /admin.html?section=training 右侧模块。共享 TrainingPanel、成员今日训练及旧随机挑战接口保留。

列表支持标题/状态筛选和分页；新建按“任务与题单 → 身份与周期 → 发布确认”操作。题库和标准题号经服务端校验、去重，题单可排序、删除；预览显示动态身份并集、排除原因和未绑定人数，有排除时必须确认。

地址参数 task_id / tab / step / page 可刷新与直接访问；名单预览凭证不写入 URL 或本地存储，刷新发布确认页须重新预览。未保存离开提示覆盖后台内部模块与同模块的任务切换；组件退出取消请求。

已发布任务可查看冻结题单、分页成员进度、个人逐题证据，以及带原因延期/取消。人数与题数分别展示，异常账号保留分母。
