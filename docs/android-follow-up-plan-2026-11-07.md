# App 后期更新计划（2026-11-07）

状态：根据维护者本轮取舍登记，尚未实施，不代表已通过评审、指定版本或安排上线。基线为已发布 v0.2.22。本轮先实施图片故障恢复、帮助与说明、存储管理，见[本地实现记录](android-recovery-storage-help-local-2026-11-07.md)。

## 后期处理项目

| 项目 | 当前情况 | 后期范围 | 本轮边界 |
| --- | --- | --- | --- |
| 发布稳定性 | v0.2.22 首次发布在草稿查询/上传前检查失败，重跑成功 | 定位真实原因、保留草稿 ID、有限重试和恢复说明、对应发布失败测试；继续校验附件，禁止覆盖已发布制品 | 不修改发布脚本或 Actions |
| 内容分享与系统打开 | 主题文件已有系统分享；帖子/题目/Wiki 缺少统一分享和系统链接直达；主题需要从 App 内选文件导入 | 复制/分享内容链接、登录后恢复目标、接收主题文件并复用安全校验 | 不新增导出 Activity 或链接路由 |
| 阅读便利性 | PDF 已有翻页/缩放/适宽，图片已有单张放大拖动 | PDF 跳页、手势和再次打开的阅读进度；图片保存、分享和多图连续查看 | 本轮只补图片读取失败恢复 |
| 设备验收覆盖 | 维护者反馈目前只试过安卓机，苹果未试过；鸿蒙有个别 Bug 但能用；仓库另有 API35 模拟器测试记录 | 汇总具体手机/系统版本与复现步骤，再安排多个 Android 版本、大字体、读屏和不同品牌测试；鸿蒙逐项记录处理 | 暂不调整兼容实现或扩展测试矩阵 |
| 版本状态文案 | 已发布 APK 的人员快照仍保留构建时“待评审与发布”状态 | 用快照日期和来源解释时效，后续版本补录真实评审发布记录，维护文档入口 | 不更改已发布 Tag/APK，不在本轮重写人员状态 |

当前交付物是 Android APK。苹果/iOS 目前没有对应客户端，不能通过把 APK 放到苹果手机上完成兼容验收；如以后需要 iOS，单独评估客户端与分发方式。鸿蒙反馈未附具体系统版本，不能据此宣称所有鸿蒙版本或 HarmonyOS NEXT 均受支持。

## 执行条件

每项开展前先确认明确范围及可复现标准，通过本地验证后走 PR 和跨人 Review，取得合并/发布授权后再创建新版本 Tag。此计划不要求现在处理，也不把缺失业务 API 纳入本轮。
