# Excel 批量开户操作说明

> Issue #84，2026-11-03。功能已实现，发布前仍需完成 PR 评审、备份及运维确认。仅具名 Web `admin/root` 可操作。

## 入口与启用

管理中心 → 成员账号 → **Excel 导入**，或打开 `/admin.html?section=accounts&tab=import`。

部署默认关闭新增导入。运维核对依赖和迁移后，设置 `ACM_ACCOUNT_IMPORT_ENABLED=true` 并重启 API。关闭开关会停止新上传及提交，已有批次仍可查询、下载未过期的报告和停止后续创建。旧共享管理登录不能使用导入，请改用个人 Web 管理账号。

## 填写模板

下载页面提供的 `.xlsx` 模板，只填写“导入数据”页第二行起的内容。保留三个工作表、表头和 `_meta` 版本，不增加密码或权限列。

| 字段 | 规则 |
| --- | --- |
| QQ号 | 必填，4–12 位数字且首位非 0，使用文本格式 |
| 昵称 | 可留空；新成员留空时使用 QQ，不从姓名推导公开昵称 |
| 姓名 | 可选，仅按既有个人资料权限使用 |
| 身份 | 可选文本，与 Web 角色无关；新身份值会提示确认 |
| 学校 | 可选 |
| Codeforces账号、AtCoder账号、校OJ账号 | 填账号标识，不能填网址或密码 |
| 洛谷UID、牛客UID | 填数字 ID，推荐文本，超过 Excel 可靠有效位的数字值会拒绝 |

单文件最多 5 MiB、200 个非空数据行。空白行忽略，但错误提示仍使用原 Excel 行号。拒绝公式、宏、外部链接、隐藏行列、合并单元格、未知工作表和额外列。

同表 QQ 或新成员的同平台 OJ 标识重复时，所有相关重复行均报错，不自动选择其中一行。

## 预检与选择

上传并校验后查看逐行结果。预检只保存导入台账，不建成员、不开户、不覆盖资料、不触发同步。

| 现状 | 执行动作 |
| --- | --- |
| 新 QQ | 新建成员档案及普通 Web 账号，按确认录入 OJ |
| 已有成员但无 Web 账号 | 仅补开户，表内其他资料即使旧值为空也忽略 |
| 已有 Web 账号 | 跳过，不重置密码 |
| 已停用账号 | 阻断，不自动启用 |
| 已注销身份（#83 生命周期存在时） | 阻断；需要管理员在单个创建入口显式创建新代际 |
| 字段错误、重复或 OJ 占用冲突 | 不可执行，修正后重新上传 |

逐页选择可执行行；“选中本页”只选择当前页。提交前可以展开完整所选名单，包含其他页所选对象。涉及 OJ 时勾选对应关系确认。

预检有效 30 分钟。第一次确认会冻结名单和动作，后续不能偷偷加入其他行。预检后发生建档、资料、绑定或账号变化时，提交返回冲突，需要重新核对。

## 创建、暂停与恢复

点击确认后每段处理 10 人。系统逐行提交，某行冲突不会撤销前面已创建的账号。密码计算在写事务外执行，不等待外部 OJ。

“暂停后续创建”等待当前段返回后停止后续段；“停止此批次”永久取消未处理行，保留已成功账号。首次确认后有 2 小时的执行窗口。

离开、刷新或断网后，使用含 `import_id` 的原地址查询恢复结果，页面不会自动继续创建。确认当前段已结束后，明确点击“继续未处理成员”。租约过期的中断段可恢复未处理范围，旧处理者不能迟到提交。

管理员被停用、降权、注销或凭据版本变化后停止后续创建；序列化密码前再次检查权限。凭据变化后的旧批次只读，需要重新预检。root 可以审计其他操作者的无密码结果，不能接管创建或领取密码。

## 领取初始凭据

每人独立生成 24 字符强随机初始密码，沿用现有临时密码有效期（默认 72 小时，支持原配置），首次登录必须修改。

密码只在创建该段的原始响应中返回，当前页面可显示、复制或下载纯文本。离开或刷新后清除，不写浏览器存储、URL、数据库、日志或普通结果报告。自动复制失败时可手动复制。

**账号成功但未收到密码，与开户失败不同。** 先查询成功名单，再到“账号管理”明确重新发放临时密码；重发会使原密码失效。重复点击或相同请求重放只返回无密码结果，不会再次开户、重置密码或恢复明文。

## OJ 来源与同步

新成员导入绑定来源为“管理员录入”，本人归属未核验、平台存在性未检查、尚未同步。Codeforces 后续通过现有本人验证码验证后，来源更新为“本人核验”，包括验证相同 handle 的情况。

导入不自动同步。需要统计时使用已有受控同步入口；同步失败不会撤销账号。补开户不会清理原绑定、AC、提交证据、挑战和同步游标。

## 报告与保留

无密码结果报告为 `.xlsx`，所有用户文本强制字符串输出，不生成公式或超链接。

原始上传解析结束即删除，异常遗留超过 1 小时后由清理任务回收。预检和执行资料副本在终态后 24 小时到期（未确认批次从上传起计）；到期读取即清理，启动、每小时及上传时也执行有界清理。最小台账保留 90 天，绑定来源随当前绑定生命周期保留。备份副本使用部署方既有保留政策，运行库清理不等于删除全部备份。

## 发布与恢复

发布前备份数据库和上传目录，安装锁定的 Excel/XML 依赖，执行重复初始化及回归。新增批次、行、段、绑定来源四张表，不删除旧业务表。

异常时先关闭导入开关并查询已成功行。代码回退不会撤销开户；保留新表、台账和既有账号，禁止删除账号后重试整批。新旧版本及 #83 的最终合并版本须再做发布联调，本地合成验证不替代生产确认。
