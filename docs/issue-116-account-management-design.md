# #116 成员账号维护：实施方案

日期：2026-11-10。基线：上游 main `d82aebc`。父任务 #80。

## 目标与边界

- 顶层「账号管理 / 开通账号」分开。开户内部提供「单个成员开通 / Excel 导入」，保留给既有成员发号、单独创建和重新开户的现有流程。
- 保留旧 `tab=import` 深链；增加 `tab=open`，不重做开户和 Excel 导入业务，不修改成员资料编辑功能。
- 账号管理采用逐人列表：选择、QQ、真实姓名、最近登录、权限/状态、临时密码、权限更改，以及原有启停/手动设密能力。
- 不新增数据库表，不持久保存密码，不引入新的批处理任务系统或大型 UI 库。

## 页面与状态

1. 将现有开户部分提取为 AccountOpening，账号列表由独立组件维护。上部导航的开户内部切换已有表单和 AccountImport。
2. 列表 GET 仍向后兼容返回数组，增加真实姓名、account_epoch、credential_version；不返回密码 hash。前端对完整数组进行搜索和 20 人分页，URL 保存账号搜索/页码。
3. 仅当前页可勾选，全选明确为当前页，页码/搜索变化清除选择；成功后移除成功项，失败项保留定位和原因。
4. 单人/批量共用操作流程。确认目标和影响后逐人提交（串行），进度与逐项结果可见。角色修改仅 root 可发起，管理员敏感目标继续保留既有授权规则；自我权限变更排最后。
5. 不将失败/状态未知的请求自动重试；权限失效时停止后续队列。请求最终提交仍在服务端逐项复核权限。

## 后端最小调整

- GET 账号列表补充真实姓名、代际、凭据版本；关闭账号继续隐藏完整 QQ。
- 现有 PATCH/手动改密/临时密码接口接受可选 expected_account_epoch、expected_credential_version。新 UI 必须携带；旧调用者保持兼容。事务中比较，409 时不覆盖。
- 临时密码接口允许 active 的普通 member（包括完成首次改密者）重设；仍不借此扩展管理员/root 的随机密码权限。随机新密码有效期沿用配置，must_change_password 重置为 1，凭据版本递增使旧密码/会话失效。
- 先读成员代际/版本并生成 hash，最终事务复核操作者角色、目标 active/代际/版本/角色，避免 hash 期间重开户或撤权竞争。返回真实姓名、QQ/username、新密码、到期时间及写后的版本；响应不缓存。
- 权限修改沿用 protect_last_root，不能通过多选绕过；目标身份/状态不再匹配时失败，不重新开户。

## 密码表与会话安全

- 复用现有安全 XLSX 生成器，增加可选表头/工作表名参数，默认开户导出行为不变；密码维护表为 QQ号、真实姓名、账号、临时密码。
- 只导出本页已领取成功结果；缺失真实姓名留空，所有单元格使用文本类型，防止科学计数法/公式解释。
- 凭据只在当前组件内存；重复导出同一快照不调用重设接口。多次操作按成员维护最新已知凭据，重复重设前删除该成员旧凭据，避免状态未知后继续导出失效密码。
- 新响应必须属于同一管理员会话。身份/代际/角色变化后清空敏感内存；卸载、pagehide 清理；未领取/未导出及操作中离开需提醒。
- 批量中途退出不在后台继续发送新请求。断网/超时明确提示可能已生效，不声称未修改；导出仅包含已收到成功响应的成员。

## 验证计划

- 后端：完成首次改密者重设、旧密码失效/新密码首次改密/有效期、真实姓名返回、越权/停用/注销、过期代际/版本、hash 期间目标换代/操作者撤权、最后 root 保护、旧开户接口回归。
- 组件：导航和旧导入深链、表格空值、当前页全选、跨页清除、确认取消、批量部分成功/失败、权限失效停止、自我修改排后、密码导出仅成功项/重新下载不重设、切换身份不泄露。
- XLSX：真实工作簿与文本单元格，空姓名不回填昵称，开户默认表头不变。
- 浏览器：桌面/手机表格、导航和密码导出交互，使用合成数据。
- 最后运行前端测试/构建及后端相关回归，review 差异后提交 PR，正文写 `Closes #116`。
