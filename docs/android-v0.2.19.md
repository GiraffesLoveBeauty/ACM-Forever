# Android v0.2.19：搜索手势、下拉刷新与便捷管理

状态：2026-11-06，本地候选版 `0.2.19` / versionCode `33`；起始基于 main `f30b33cf`、提交前同步 main `b27c2334`，提交独立 PR 等待跨人 review，不创建 Tag、不发布新版 APK。包名、固定调试签名及现有 GitHub 更新渠道继续沿用。

## 搜索与刷新

- 搜索页只保留顶部一个“搜索设置”；圆形搜索按钮位于关键词输入框右边，键盘搜索与历史记录仍走统一提交逻辑。搜索历史开关、去重、十条上限和单列优先级不变。
- 搜索设置删除三条杠，整卡任意位置长按进入排序。全部模块缩至90%，选中卡片只跟随手指纵向移动；相邻模块根据越过的中点调整顺序，以150ms动画补位，松手180ms恢复大小并保存本机顺序。边缘拖动自动滚动，取消不保存；无障碍用户可执行“向上/向下移动”。删除使用既有猫娘叉图标，添加使用放大的原创方角加号。
- 新增顶部下拉刷新：下拉显示提示，达到阈值后显示“松开刷新”，松手重新读取当前页，显示实际读取状态。覆盖主页面壳、搜索结果、便捷管理、我的空间、Wiki/通知等网页能力页、训练工具页以及检查更新页。
- 刷新复用 `PageRefresh` 当前代次注册的只读请求，保留页面位置、查询和筛选；不重发发帖、评论、点赞、自动保存、审核、改密等写操作。发帖编辑页不启用下拉刷新，模块排序期间父滚动容器不能抢夺手势。
- 十秒连接预警、持续只读重试、关闭警告以及重连成功三秒关闭的既有规则不变。已经在读取时不排队重复刷新。

## 更新检查

启动仍在会话处理后的第5步异步检查，自动检查默认开启，已保存的关闭设置继续有效。同一进程不因旋转重复启动检查。六小时节流现在依据**成功读取清单**的时间；失败仅作一分钟防抖，不再占用六小时成功间隔。下一次进程启动可重试；本轮没有新增常驻后台更新服务。

进入“检查更新”页面即进行一次手动检查，不受六小时节流影响；旋转不重复检查，已有下载/校验任务继续运行。页面显示最近检查时间和成功/失败状态，也支持下拉或按钮重新检查。失败不会声称“已是最新版本”。发现新版本和已是最新的确认弹窗、猫娘下载页、SHA-256/包名/版本/签名校验、系统确认安装继续沿用。

更新源仍是 GitHub Release `latest/download/update.json`，与业务 API 独立。自定义清单失败不会偷偷改回默认源。国内设备若无法直连 GitHub，仍可能检查或下载失败；本轮不把等待管理员配置的自站 #105 作为已上线功能。同版本不会弹“有新版本”。

## 管理员与成员操作

普通成员的账号设置不显示管理员模块；内部管理 Activity 进入及恢复时验证服务端会话，所有管理读取和写入都在后台重新检查角色。成员私有资料不进通用缓存，写请求继续带 CSRF；UI 角色不会替代后端鉴权。

| 页面 | 行为与既有 API | 权限与边界 |
| --- | --- | --- |
| 同步任务 | `GET /api/tasks`、`POST /api/tasks/{id}/cancel` | OJ提交记录同步、题目采集等任务的状态查看与取消；中文状态、进行中/已结束筛选、进度、采集成功/失败摘要、失败原因和时间；不直接堆原始JSON，不自动重新采集 |
| 成员列表 | `GET /api/admin/members/options`、`GET /api/admin/members` | 用户名/真实姓名/QQ/OJ关键词、学校与身份组合筛选，20项分页；资料卡展示实际返回的姓名、学校、身份、绑定、账号角色及启停状态，点击整卡进入管理，不再放“查看资料”按钮 |
| 成员资料 | `GET/PATCH /api/admin/members/{qq}` | 用户名、姓名、学校、身份和四个OJ绑定；携带当前 `expected_account_epoch`、`profile_revision`，修改绑定另带旧绑定及版本，并确认清理影响。版本冲突要重新读取，不强行覆盖；同步派发警告需展示，不能误报整个保存失败 |
| 登录密码 | `POST /api/admin/web-accounts/{qq}/reset-password` | 设置符合后端规则的新初始密码，旧会话失效、下次必须改密；不读取旧密码，不保存输入。普通管理员只能操作成员，Root可操作管理账号，服务端作最终判断 |
| 账号启停与角色 | `PATCH /api/admin/web-accounts/{qq}` | 启停前确认；仅Root显示角色操作。后端保护最后一个Root，账号变更后重新验证操作者会话 |
| 训练资料 | `GET /api/member/{qq}`、训练/复盘既有接口 | 展示实际平台题数、最近AC、挑战分及返回的比赛资料；最近AC进入App题面。保留训练生成和复盘入口，平台与难度选择框统一圆角 |

`is_active` 在新的成员快照中可能是数据库数字0/1，也可能是布尔值，两种都正确识别。缺少接口或资料时展示真实错误；旧服务端未部署这些已存在于源码的成员接口时，不能把失败当成成员没有资料。QQ、校OJ、批量开户、Excel、题库采集、Wiki编辑等复杂维护仍到Web操作。普通成员自己的OJ绑定入口继续提示到网页或联系管理员。

本轮不新增业务API，不修改网页/后端源码、发布工作流、服务器或自站PR，没有在生产执行成员写操作。

## 图标与官方主题

顶栏加号改为原创矢量实心十字，交叉处方角；按钮仍跟随主题，无复制第三方素材。猫娘叉及其他既有图标系统继续使用。私人主题系统分享保持v0.2.18行为。

保留原生ACMForever模板，官方主题另用原CSS横幅背景层加原Vue/SVG交互层。原生文字与图谱保持独立列；背景层按文字内容测量，避免WebView撑大横幅。方块工坊图谱恢复230px设计高度、天使之城保留35px上偏移和230px高度、相变信号保留12px上偏移和265px高度；统一在400×300场景中等比适配，不再把不同模板内部图层一律撑满。

背景、装饰、地形、字体及节点来自已打包原源文件，没有截图替换、重绘或远程脚本。原生业务控件仍用共享样式接收颜色和形状；网页DOM的全部字体/控件效果不等于自动覆盖Android View。资源指纹、无损主题往返及工业黄浅深覆盖继续保持。
