## 0.1.11 上一轮功能

- **检查更新**：账号设置和顶部工具只提供检查按钮，已移除 API 地址与清单地址表单。发布接口尚未提供，联网时显示红色“无API接口”，断网显示“无网络”；仅服务器成功返回有效清单且没有更高版本时显示“已是最新版”。有新版本时显示“更新X.X版本”，确认后下载、校验并交安卓系统安装器。检查、提示和下载阻止重复触发。
- **保存密码**：登录保留“记住我”和“自动登录”，新增可选“保存密码”。Android Keystore AES-GCM 加密，绑定服务器与账号，只有登录成功后才保存；改账号清空输入，取消保存、退出和成功改密会删除保存密码。自动登录继续恢复并联网验证有效会话，失效后回登录。
- **完整管理员界面**：顶部头像 → 账号设置 → 管理员栏 → 管理中心。仅服务端确认的 `admin/root` 显示，进入再次读取 `/api/auth/me`；普通成员不能加载管理模块。将现有九个 Vue 模块打包进 APK，适配手机导航、表单、横向表格和错误面板，复用已有管理 API。
- 管理模块：成员账号、成员资料、训练管理、题库管理、CF 练习赛选题、赛事复盘、同步任务、内容审核、全局设置。包含发放/批量/重置账号、角色权限、题目采集与任务恢复、审核、设置等现有网页功能；Root 限制仍由服务器决定。临时账密保留离开提醒，复制与 CSV/主题导出使用原生剪贴板、文档选择器，主题导入使用系统文件选择器。
- 管理界面使用本地可信资源及受限原生桥，网络通过现有 HTTPS ApiClient 会话和 CSRF。密码/Cookie 不导出给 JS；远程页面不能加载原生桥。原网页文件没有改动，也不需要二次网页登录。

## 现有页面与数据

底部：主页（论坛）、排名、中央“＋”发帖、题库、个人中心。顶部：头像进入账号设置、搜索、小矢量“＋”常用工具；社区话题右侧漏斗统一分类与排序，防止重复弹窗。

- 登录：用户名 / QQ 和密码 → 独立等待页 → `/api/auth/me` 确认 → 返回原操作；慢请求提示 Tailscale，失败保留账号并显示红色原因，初始密码进入改密。
- 论坛：真实分类/搜索/分页/排序，Markdown/公式、点赞/收藏/举报、评论和一层回复；云端草稿增删改查、预览、提交审核和离开提醒。草稿需主动保存，进程重启前应保存到服务器。
- 排名：7/30/90/365 日及生涯、平台和排序筛选。题库：筛选、收藏、已采集题面/样例及复制、应用内 HTTPS 外链。
- 搜索：独立输入页，最多 10 条去重历史方框，点击或提交后显示结果；单条删除、清空与关闭记录，只存本机。
- 个人中心是公开主页，只展示用户名、座右铭、平台通过题数及已发布话题。本人统计复用 `/api/me/profile` 顶层计数；本人话题复用 `/api/forum/mine/posts`，筛选 published，受最近 100 条限制。座右铭失败不会遮住统计和帖子。
- 账号菜单：昵称、头像、密码、OJ 绑定摘要、私有最近 AC/收藏/草稿、三档训练/历史/统计和赛事逐题状态。管理员工具留在账号设置。
- 他人公开身份、资料/帖子与座右铭使用此前本地新增的 `/api/mobile/v1/*`，尚未部署时对应区域显示“无API接口”。客户端不直连数据库。
- 错误保留内容区域高度：无API接口、无网络、未配置服务器、未登录、无权限、超时、服务器异常、内容不存在、安全连接失败、数据格式异常；成功空数据显示“暂无内容”。没有演示身份、合成内容、虚假成功或接口记录入口。
- 相机扫码尚未实现；原生支持粘贴 HTTPS 链接，确认后在 App 内打开。

## 浏览器预览与构建

后端故障时，可打开 [offline-v0.1.12.html（离线界面预览）](prototype/offline-v0.1.12.html)，或为 `index.html` 添加 `?offline=1`。该模式不请求 API，不恢复登录、不伪造用户或业务数据；导航、搜索历史、正文编辑与本地预览可用，分类和数据区域显示离线提示，登录、云端保存、发布与检查更新不可用。编辑内容只在当前页面内存中保留，关闭后丢失。此入口仅用于浏览器界面预览，未修改 APK。

打开 [prototype/index.html](prototype/index.html)。浏览器 API 访问受 CORS/凭据策略限制，后端未为本地预览新增跨域配置；原生请求不受此限制。浏览器“保存密码”交给浏览器密码管理器，不支持 Credential Management API 时禁用，已保存项由浏览器管理。浏览器只下载 APK，不能执行 Android 原生安装与校验。管理中心 iframe 复用相同打包资源，保留服务器角色校验。

管理 UI：先按仓库既有方式安装 `feat/web` 锁文件依赖，然后在 `Android_APP/admin-console` 运行 `npm run build`。读取原 Vue 源码与依赖，只写 Android 资源目录；生成 IIFE 以支持 file 预览，并收集实际打包运行时的许可证。

Android 工具链：JDK 17、SDK 35、Gradle 8.9、AGP 8.7.3。在 `app/` 运行：

```powershell
.\gradlew.bat assembleDebug
```
