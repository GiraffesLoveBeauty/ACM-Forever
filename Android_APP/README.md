## 当前功能

底部为主页（论坛）、排名、中间猫娘剪影发帖、题库、个人中心；顶部头像进入账号设置。社团训练位于题库“训练工具”，含题单、按题讨论、错题本、补题复习、Wiki 和打卡提醒，退出训练返回实际来源页面。重管理仍由 Web 承担。

保留话题收藏/我的收藏、云端多草稿/自动保存/切换/删除、Markdown 编辑与导入；排行榜近 7/30/90/365 日及生涯、多平台组合、排序、每页 10/20/50/100 人；PDF 翻页、缩放、适应宽度；网页六态赛事复盘。排行榜排除所选平台合计通过数为零的成员，旧服务器也会在客户端重新过滤、分页。

登录提供“记住账号”“记住密码”“自动登录”三项，密码右侧小眼睛切换可见性。自动登录会同时记住账号与密码；只记住密码时仅填充表单。密码和持久会话使用 Android Keystore 的 AES-GCM 加密保存在本机，密码绑定服务器与账号。自动登录优先验证会话，会话过期后尝试保存的密码；断网不删除有效保存项。退出、修改密码或取消记住选项时清理相应保存项。同签名覆盖安装保留设置与凭据；卸载或清除应用数据会删除。

成功读取的 JSON 页面缓存位于进程内，按服务器、会话和完整请求区分；返回页面立即回显，再后台更新。PDF 缓存最多 5 份、64 MB，头像缓存最多 64 张。退出/换账号/换服务清除对应缓存；首次没有成功数据时显示真实错误。缓存与保存的登录凭据独立。

全部业务数据来自 API。不存在的接口、断网、服务器异常、未登录与空结果分开处理。五项训练能力仍依赖服务器实际功能；本轮未部署后端，缺少接口显示红色“无API接口”，不会补假数据。

本机外观：头像 → 账号设置 → 个性化设置 → 背景选择 / 主题选择。背景作用于全屏底图；图片有六档透明度，默认 40%；纯色/渐变支持与主题同色或自定义。渐变下半为白色。主题模块背景另有独立六档透明度，默认不透明。颜色和透明度原位更新。主题库含原有设计、相变信号、天使之城、方块工坊和五套配色，支持浅深色及本机 JSON 导入；原神/绝区零为空分类。Android 适配原生配色和几何样式，不复刻整套网页 CSS。图片及外观设置只保存在本机。

新增入口：主页右上角图标 → 通知中心 / 我的投稿 / Wiki 手册 / 比赛进度；账号设置也有通知与投稿进度，题库内也有比赛进度。投稿保存和提交携带最新版本，冲突保留输入。成员页从论坛/排名头像进入；本 PR 含公开成员 ID、资料和话题接口，已适配主线账号注销/重新开户规则。正式服务器是否部署仍待联调，缺失区域显示“无API接口”，不借用私有接口或排名区间题数替代。

本机参考库位于 `E:\爱臭美工程\森空岛素材库\index.html`，可搜索、分类、分页查看 607 个参考图标。按本轮要求，仅取本地 `legacy-reference/sk_add.xml` 作为搜索右侧加号；其余参考库未打入 APK。现有插画、重绘图标与官网平台 Logo 保留，来源见美工说明与本轮处理文档。

## 源码与构建

`app/app/src/main/java/.../MainActivity.java` 为论坛、排行、题库和账号界面；`CloudDrafts.java` 为串行自动保存；`PdfActivity.java` 为原生 PDF 阅读；`ClubActivity.java` 为训练功能；`ResponseCache.java`、`PdfFiles.java`、`PageRefresh.java` 负责缓存与刷新提示；`SessionVault.java` 负责加密保存；`MobileStyle.java`、`AppIcons.java`、`CodingCatView.java`、`ProfileCover.java` 与 `CommunityArtwork.java` 负责样式、图标和装饰。8 个模板位于 `assets/templates/catalog.json`。

工具链为 JDK 17、SDK 35、Gradle 8.9、AGP 8.7.3。执行 `:app:assembleDebug :app:lintDebug :app:testDebugUnitTest`。PDF 原生烟测使用独立 `src/androidTest` 测试包，不进入交付 APK。调试签名沿用被忽略的 `dist/signing/debug.keystore`，不得提交密钥。
