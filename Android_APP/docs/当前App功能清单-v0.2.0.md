## 一、入口目录

```text
顶部头像 → 账号设置（仅本人）
  ├─ 登录：记住账号、等待结果、强制修改初始密码
  ├─ 个人资料：昵称、头像、OJ 绑定摘要
  ├─ 我的学习：通过题数、最近 AC、题目收藏
  ├─ 社团训练：题单、错题本、补题、模板、打卡
  ├─ 今日训练：到期补题、三档推荐、训练统计和历史
  ├─ 赛事复盘：未做 / 待补题 / 已解决 / 忽略
  ├─ 我的社区：本人话题、本机草稿
  └─ 修改密码、关于、退出登录
顶部搜索 → 最近 10 条搜索历史 / 历史设置 → 搜索结果
底部主页（论坛）
  ├─ 分类与排序：社区话题右侧筛选入口
  ├─ 详情、Markdown/公式、点赞、评论/回复、简单举报
  └─ 社团训练入口
底部排名 → 周 / 月 / 总、单平台筛选、固定 20 人、上下页
底部加号 → 简单发帖、本机草稿、预览、提交审核
底部题库 → 筛选、题目收藏、题面/样例、原题外链、本题讨论
底部个人中心 → 昵称/头像、平台通过题数、本人已发布话题
社团训练
  ├─ 社团题单 → 截止时间、完成进度、题目列表
  ├─ 按题讨论 → 搜索/错因标签、发帖、评论与举报
  ├─ 错题本 → 私有错因标签/笔记、编辑、移出
  ├─ 补题与复习 → 到期列表、完成、明天再练、忽略
  ├─ 离线模板 → 搜索、阅读、复制
  └─ 打卡 → 目标、真实 AC 验证、连续天数、本地提醒
Web 管理后台（保留原管理功能）
  └─ 新增社团题单 → 创建、指定成员/全员下发、查看成员进度
```

个人中心“公开信息”与账号设置继续分开。此次不建设完整他人公开资料接口依赖；点他人头像显示已有响应中的成员摘要，不猜测身份，不公开最近逐题提交或 OJ 绑定。管理员完整操作移到 Web，App 不再显示管理员管理中心。

## 二、现有功能如何精简

| 功能 | 本轮行为 |
| --- | --- |
| 手机九大管理模块、CSV、主题、导入导出 | 去掉入口、Activity 注册和主构建内容；保留旧源码及原 Web 后台 |
| 扫一扫和顶部工具加号 | 去掉入口 |
| 更新下载、SHA-256、安装器流程 | 本轮后置，无更新菜单、安装权限或发布接口 |
| 应用内浏览器 | HTTPS 外链由系统浏览器打开；阅读论坛/题面用的本地阅读器仍保留 |
| 保存密码、自动登录、持久会话 | UI 去掉；启动清理旧保存值，只记住账号；进程内会话保留 |
| 排行榜 | 周/月/总、单平台、20 条/页、上下页；零 AC 不显示 |
| 赛事复盘 | App 四态；既有 Web/API 六态保留，旧 unsolved 显示待补题、reviewed 显示已解决 |
| 云端草稿 | App 改用本机按服务地址/账号保存的草稿，再直接提交帖子审核；既有 Web 草稿接口保留 |
| 话题收藏、座右铭编辑、他人完整资料 | App 入口后置；题目收藏保留 |
| 聊天、好友、私信、在线判题 | 未加入 |
| 其他 P1/P2（约练、赛历、教练看板等） | 未纳入本轮 |

登录后 Activity 重建使用 Application 中的同一 ApiClient；重启进程需要重新登录。退出时即使远程注销失败也清理本机状态及提醒，并告知远程注销未确认。

## 三、五项新增能力的实际范围

### 1. 社团题单

管理员在 Web“社团题单”填写标题、说明、北京时间截止时间、平台和题号，成员名单留空为全员，也可指定 QQ。App 只显示有权查看的题单及本人进度；成员进度明细仅管理员可读。每题按既有 submissions 中的真实 AC 判断，支持历史题号前缀规范化；不是手动点完成。全员题单包含后续加入成员；指定题单不会因成员被删除而变成全员题单。

题单先做创建与下发，不包括修改、撤回、附件、逐题评分和逾期冻结；完成情况是当前累计 AC，不追溯“截止前是否完成”。列表取最近 100 个题单，每单 1–100 题，最多指定 500 人。

### 2. 按题讨论与错题本

平台＋题号关联现有论坛帖子；新讨论为 pending，经过既有 Web 审核后出现。支持关键词和 WA、TLE、输入格式、边界、复杂度、思路、其他标签筛选，最多展示最近 200 条已发布讨论。评论、回复和举报跳转原论坛能力，没有第二套聊天系统。

错题本按当前成员隔离，可记错因标签及最长 2000 字笔记、编辑和移出，最多读取最近 500 条。不把加入错题本当作真实做错或真实 AC 的证据。

### 3. 补题与 1/3/7 天复习

现有 CF 赛事复盘写入 unsolved/queued 时，同一事务加入补题计划；读取补题列表时补入历史待补题记录，忽略/结束的计划不因重复读取重开。手动也可从本题讨论页加入其他平台题目。原有历史 Web 复习/计划接口仍维持 410，此次使用独立 club 表和路径。

首次立即到期。点击“本次复习已完成”后依次等待 1、3、7 天，第四次完成关闭计划；未到期不能提前连续完成。不会可延后一天，忽略可关闭，已关闭需要明确重新加入。计划每次最多读取 500 条；今日训练直接显示其中的到期项。

这里的复习完成是成员主动确认，不等于 OJ 评测通过；真实 AC 仍来自同步表。CF 赛事改为 solved/reviewed/ignored 时关闭对应补题计划。未实现跨赛事冲突合并策略或其他平台赛事导入。

### 4. 离线模板

快速 IO、并查集、Dijkstra、BFS、树状数组、模快速幂、半开区间二分、Python 对拍脚本，共 8 项。随客户端资源打包，支持搜索名称/标签/说明、查看、复制，无网络也能使用；不在手机执行代码。模板为本项目原创整理，写明适用条件；大部分 C++ 内容是需补头文件的片段，`__int128` 依赖 GCC/Clang。Python 对拍仅供电脑端使用。

### 5. 打卡及本地提醒

每日目标 1–100 题，服务端按北京时间当日已同步 AC 去重验证；未达标返回 409，重复打卡更新当天记录，不重复累计。返回当天状态、最近最多 366 天记录和连续天数；本机保存用户目标供下次输入。

用户主动设置每日提醒时间，并在 Android 13+ 授予通知权限。AlarmManager 使用非精确提醒，系统省电/强行停止可能导致延迟或不触发。复习提醒仅依据最近读取并缓存的计划，最多安排 64 个未来提醒；打开补题页/今日训练后刷新缓存，无后台联网同步。重启设备恢复已缓存提醒；退出登录或关闭提醒取消计划。通知内容不含私有题目和成员信息。浏览器预览不模拟原生通知。

## 四、接口与数据边界

客户端继续复用既有认证、论坛、题库、排行、资料、训练和赛事 API，不直接连接数据库。新增仅包括题单、按题讨论关联、私有错题/复习、打卡，契约见 [api.md（社团训练接口）](../../docs/api.md#社团训练闭环-v020本地实现)。7 张 club 表只在后端初始化，不覆盖旧论坛、提交或旧复盘表。

缺失接口用红色“无API接口”；断网“无网络”；超时、未登录、无权限、服务异常、格式异常分别处理。错误保留内容区域高度；成功空列表展示“暂无题单/错题/补题”等。新接口未部署时不会展示虚构训练或假进度。
