二、交付三种用途

三、必须真正分层，不能只改变扁平图的色相

2. clothes：衣服主体。
3. decor：蝴蝶结和可换色装饰。
4. fixed：肤色、脸颊、猫耳、领子、袖口花纹、电脑及其他不应换色的区域。

请准确划分部件边界；固定区域不得被发色、衣服色、装饰色污染。头发高光、发梢、蝴蝶结褶皱、衣服阴影和半透明抗锯齿边缘都必须自然，不能出现原色残留、硬切边、荧光轮廓或大片糊色。

每组可以拆成多个部件，以保留头发前后遮挡、手和袖口、领子与蝴蝶结的正确层级。不要把所有 fixed 部件强行合为最后一层，导致遮挡关系错误。

四、导出要求
1. 交付可编辑的 SVG 或 PSD/KRA 等原生分层源文件，图层命名清楚。

3. layers/original/：每个部件的原配色透明 PNG。
4. layers/neutral/：可换色部件对应的中性灰阶明暗 PNG，保留相同 alpha 与全部高光阴影；固定部件不需要中性灰副本。
5. masks/：每个换色组的独立透明度遮罩，边缘与图层准确匹配。请用已分好的真实图层生成遮罩，不要重新按像素颜色猜范围。
