# ACMforever v0.2.9 本地调试包

包名 `com.giraffeslovebeauty.acmforever`，versionCode `23`，最低 Android 8.0（API 26）。

安装包：`Android_APP/dist/acmforever-0.2.9-debug.apk`。沿用 v0.2.8 调试签名，可覆盖安装并保留账号、已保存密码、背景与其他本机设置。

## 本轮变更

1. 训练工具的算法模板入口改为 Wiki 手册，复用网页现有 Wiki API。
2. 每日提醒采用小时、分钟数字输入，校验 0–23 / 0–59；显示本机时间及时区，支持勾选通知提醒。Android 13 及以上按需申请通知权限；被拒绝时不宣称已启用。读取本机时间不需要额外运行时权限。提醒采用系统非精确闹钟，可能受省电策略影响。
3. 首页右上加号背景跟随主题色。按仓库网页主题文件补上工业网格、相变纯底、天使之城网格与微光、方块工坊泥土纹理。选择主题库预设时，整屏背景同步切换到该主题规则；用户随后仍可自定义。
4. 个性化主菜单为四个按钮：背景选择、主题选择、一键保存、我的主题。下面两个按钮同高异宽。
5. 一键保存创建本机外观快照，默认从“未命名1”递增命名。图片独立复制；不保存账号、密码、会话或服务器配置。
6. 我的主题：点击名称应用；“设置”打开独立编辑页，只有背景选择、主题选择、预览、重命名四项。修改自动保存到该主题，暂不影响 App 当前外观。
7. 主题预览使用明确的假主页，标题与目录保留，其余内容使用 ACMForever；左上半透明红色圆形猫娘 × 用于返回。重命名预填当前名称，支持确认与返回。
8. 我的话题、话题收藏、云端草稿改为独立页面，采用卡片、搜索、空状态和对应的查看/编辑/审核进度/删除等操作；话题支持审核状态筛选。数据只来自现有 API 或本会话缓存。云端草稿沿用编辑自动保存流程。
9. API 错误与连接/操作提示使用独立圆角模块，透明度跟随模块设置。普通等待 10 秒显示连接预警；用户点击后，若已明确连接失败且无缓存，则立即提示。持续重试只读请求，不自动重发写操作；恢复提示 3 秒后关闭。
10. 最近 AC 点击进入 App 的题库题面与样例；未采集题面会显示真实缺失状态，不外跳替代。
11. 缺失 API 清单新增网页是否已有完整功能一列，基础已有、完整未有、App 专属分别注明。

## 数据与发布边界

- 本轮只修改本地 Android_APP，不上传 GitHub、不部署、不修改网页或后端。
- 网页规则按本机已有 origin/main 34e21a9b 核对，未下载新提交。
- 保存的主题、背景图片、裁剪结果仅在本机；覆盖更新保留，卸载或清除应用数据会删除。
- 提醒设置不依赖打卡 API；打卡业务的服务器能力仍须按缺失清单补齐。
- 本机验证使用测试包隔离的模拟响应，不代表正式服务器连通或缺失接口已上线。
