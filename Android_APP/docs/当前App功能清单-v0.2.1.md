## 与网页对齐的行为

| 功能 | 本版行为 |
| --- | --- |
| 话题收藏 | 详情收藏/取消，账号菜单查看我的收藏，复用现有接口 |
| 云端草稿 | 与网页读写同一份数据；首次创建与后续修改串行，避免快速输入重复生成草稿 |
| 草稿恢复 | 同进程重建保留 Application 中的状态；未确认保存内容留本机按账号区分的备份，下次可恢复为新草稿 |
| 发布 | 先保存完整草稿再提交；显式保存/提交期间禁用编辑控件 |
| 排行榜 | 网页相同的五个时间区间、六种排序、平台组合和四种页大小 |
| 零 AC 与当日 | 按本轮“共有功能按网页来”调整：不额外过滤零 AC；当前网页无当日入口，本版也不保留 |
| 赛事复盘 | 恢复网页六态：待处理/未通过/待补题/已解决/已复盘/忽略 |
| 登录 | 记住账号、恢复服务器持久 Cookie；不保存或重放密码 |
| 头像 | 原图最多 20MB，最长边压到 1024 像素以内，压为最多 2MB JPEG 上传 |
| PDF | 现有鉴权接口下载至临时缓存，再用 Android PdfRenderer 阅读；退出清理缓存文件 |

没有新增跨设备草稿冲突合并协议，同时编辑同一草稿需自行协调。自动保存失败显示失败状态并保留文本。

## 权限与数据边界

- 私有记录仅本人访问；公开主页不展示逐题私人做题记录。
- 批量账号、CSV、完整审核、主题编辑等管理功能继续在 Web。
- 缺失接口显示红色“无API接口”，断网显示“无网络”；服务器异常、未登录另行提示；真实空结果显示暂无内容。
- 不把测试 PDF、测试账号、森空岛素材或伪造业务内容打入交付 APK。
- 本轮未发布后端。默认 Tailscale HTTPS 地址仍要求手机具备内网访问权限。

按上版取舍，扫一扫、应用内浏览器、APK 更新器、复杂管理员中心仍未启用，部分历史源码被构建排除。浏览器预览仍是 v0.2.0，本版以 APK 为准。
