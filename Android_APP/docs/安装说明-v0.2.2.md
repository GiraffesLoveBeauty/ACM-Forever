## 安装和保存的数据

已安装本地 v0.2.0 或 v0.2.1 时，可直接覆盖安装。调试证书 SHA-256 为 `88c9f163cbf379aeca7bc110f66c542a838d0d8e3970f24fd96582bec8e93fe4`，与前两版一致。调试密钥继续保存在被 Git 忽略的 `dist/signing/debug.keystore`。

覆盖安装通常保留本机设置、记住的账号以及已成功加密保存的凭据。旧版没有保存的密码不会恢复；本版登录时重新勾选“记住密码”即可。关闭记住选项、退出、改密会清理对应项；卸载或清除数据会删除所有本机应用数据。

若手机还是签名不同的早期调试包，不能直接覆盖，应先保留需要的本机内容再卸载。正式签名尚未确定。

手机通过文件管理器打开 APK，按 Android 提示允许该来源安装，然后确认。在线功能仍需要能访问正式服务所在 Tailscale 网络；离线模板不需要 API。
