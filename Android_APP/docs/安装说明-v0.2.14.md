# ACMforever 0.2.14 安装与更新说明

状态：2026-11-05，本地构建并提交源码 PR 评审；未创建发布 Tag、未发布 Release、未部署后端。APK 不提交源码 Git，对外发布由 Tag Action 构建。

## 安装包

- 文件：`Android_APP/dist/acmforever-0.2.14-debug.apk`。
- 包名：`com.giraffeslovebeauty.acmforever`，versionName `0.2.14`，versionCode `28`，最低 Android 8.0 / API26。
- 沿用 0.2.x 本机调试签名。同签名覆盖安装保留设备内的账号选项、加密凭据、背景和主题；卸载或清除数据会删除这些内容。
- `.apk.sha256` 是校验文件，手机安装时选 `.apk`。

## 本版变化

1. 在会话处理后、主页内容加载前发起后台更新检查，每个进程启动只触发一次；更新服务器故障不阻塞主页。
2. 自动检查默认勾选，尊重已经保存的关闭选项，仍至少间隔 6 小时。
3. 发现新版出现等大“下载安装包”与 50% 透明度红色“取消更新”按钮。关闭或取消后可继续使用 App，旋转重建提示，不重复发请求。
4. 点下载进入猫娘加载页，显示真实下载进度、校验、失败重试、取消与安装入口。返回后系统继续下载。
5. 已移除 Wi-Fi 自动下载选项与旧版开关，所有网络均需主动确认下载。
6. 设置页手动检查已是最新时显示“已是最新版本”窗口，下面只有“确认”；新版弹窗中间显示版本与可滚动说明。
7. 本版更新说明已加入内置离线日志，可在“检查更新”页下方查看。
8. 调试包和正式包默认使用公开 GitHub Release 的 `releases/latest/download/update.json`，不依赖业务 API；清单校验渠道，仍保留 HTTPS 自定义来源。
9. 新增 Tag 自动发布流程：核对 main/版本/固定签名，构建后先上传草稿并回读三附件，全部一致才公开。完整负责人配置与发布步骤见 [Tag 发布说明](../../docs/android-tag-release-v0.2.14.md)。

## 验证和边界

使用 `tools/build-local-v0214.ps1` 构建，`verify-local-v0214.ps1` 运行模拟器回归，`package-local-v0214.ps1` 核验版本、签名、内置日志、制品和结果一致。实际结果写入本地忽略目录 `app/app/build/qa-v0214/`。

测试使用独立测试 APK 的模拟版本清单，并验证真实 Android DownloadManager 的任务启动和取消。自有服务器 API 已不采用；生产 Release 清单→真实新版 APK→覆盖安装的全链路仍待首次 Tag 发布后真机验收。负责人需先配置现有调试签名 Secret，当前尚无 Release。

旧版 debug 首次迁移需手动安装本版或改清单来源。已安装旧本地 0.2.14/code28 的设备不会自动提示另一个 code28，可同签名手动覆盖；真实升级验收使用 code27 → code28。后续必须递增 code，不能靠重命名或修改清单来冒充升级。

下载后保留大小、SHA-256、包名、版本、最低系统版本和同签名检查；最终安装由 Android 系统确认。
