# ACMforever v0.2.5 安装说明

- 文件：`Android_APP/dist/acmforever-0.2.5-debug.apk`。
- 包名：`com.giraffeslovebeauty.acmforever`，版本 0.2.5 / versionCode 19。
- 最低 Android 8.0（API 26），目标 API 35。
- 沿用 v0.2.4 调试签名；优先直接覆盖安装，保留登录设置和本机背景。请勿为了更新而清除数据或卸载。
- 正式 API 的连接条件沿用原版本；本轮未发布后端。缺失接口不补展示数据。
- 变化见《个性化与布局更新-v0.2.5.md》。浏览器原型未同步，本轮体验以 APK 为准。

## 验收重点

1. 发帖格式与草稿工具多行排列，无横向滑动，各按钮互不粘连。
2. 账号设置首页菜单没有右侧箭头，仍可整行点击。
3. 个性化设置可选择全屏图片/纯色/渐变、六档透明度、主题主色、调色盘与网页主题库。
4. 头像/加载插画随主题分组换色，固定区域保留原色。
5. 个人中心 ALL 汇总、圆形平台标签、独立过题数和最近 AC 卡片。
6. 断网 10 秒红条、持续重试、成功绿条 3 秒自动关闭。
