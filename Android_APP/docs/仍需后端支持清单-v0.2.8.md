按照用户修正，只保留**现有接口不能补齐的能力**。本人资料、平台过题数、本人话题、收藏、草稿、图片、通知、Wiki、排行榜筛选与客户端分页等现成能力不再列为后端需求。以下是缺失的数据关联、字段或写入能力；可以扩展现有接口，不要求逐项另建一套 App API。

## 仍需小组提供的能力

| 项目 | 具体仍缺什么 | 后端最小改动方向 |
| --- | --- | --- |
| 公开成员标识 | 论坛作者与排行榜成员缺少稳定、非隐私的公开 ID，无法可靠关联他人主页 | 给现有公共列表/详情增加公开 ID；昵称不能当唯一 ID，不能把 QQ 或管理员接口直接公开 |
| 他人公开主页 | 普通成员无权查询他人公开资料、各平台累计通过数和已发布话题 | 以公开 ID 提供只读资料，给论坛列表增加作者筛选；只公开各平台题数，不公开逐题记录和绑定账号隐私 |
| 座右铭 | 本人资料无座右铭读写字段 | 扩展现有本人资料和公开资料字段；客户端限制 100 字符 |
| 社团题单 | 缺教练下发题单、题目关联、截止时间、分配对象与本人完成进度 | 题目信息和 AC 判断复用现有数据；新增题单/分配关系，创建下发在 Web 完成 |
| 按题讨论与标签 | 泛论坛无法按“平台＋题号”精确关联，缺讨论标签筛选 | 扩展论坛帖子的题目关联及标签查询；评论、审核、举报复用现有实现 |
| 私人错题笔记 | 题目收藏/状态不能保存私人错因、标签和错题条目 | 扩展个人题目状态或提供私人错题 CRUD；不要挪用公开帖子或云草稿保存私有业务数据 |
| 间隔复习进度 | 现有赛事状态可表示待补题，但不记录复习阶段、到期时间、1/3/7 天推进和与今日训练的联动 | 复用现有赛事题目及状态，增加个人复习计划和幂等推进；旧复习路由已返回 410，不能调用它代替 |
| 每日目标和打卡记录 | 训练汇总只有活跃日期和连续天数，没有每日目标、达标状态或打卡写入记录 | 扩展训练汇总及写入能力；按北京时间和已同步 AC 计算，重复打卡幂等；本机提醒无需新增 API |
| 安装包发布 | 缺当前渠道最新版清单与正式 APK HTTPS 下载地址 | 可提供版本发布接口，也可由自有服务器托管静态 JSON 和 APK；不需要 App 直连数据库 |

其中题单、讨论、错题、复习、打卡在本地工作树中存在历史后端草稿，但不在上述远端 main 中，也没有在本轮发布。不能把草稿文件当作正式服务已有能力。

## 安装包更新协议

客户端新增入口：**头像 → 账号设置 → 检查更新**。

- 手动检查；启动时自动检查（可关闭，默认关闭，最多每 6 小时一次）。
- 仅 Wi-Fi 自动下载（可关闭，默认关闭；开启时同时开启自动检查）。
- 系统下载任务、进度、取消、重启后继续追踪；下载完成校验后显示安装按钮，由 Android 确认安装。
- 默认查询同一 API 服务器的 `GET /api/mobile/v1/releases/latest?channel=debug`，正式包使用 `channel=release`。这是客户端预留约定，**不是已经上线的后端接口**。
- 也可在更新页“设置发布地址”填写自有服务器的静态 HTTPS JSON 地址。清单与 APK 应公开只读，不依赖成员 Cookie、密码或 CSRF。

清单字段：

| 字段 | 要求 |
| --- | --- |
| `packageName` | 必须为 `com.giraffeslovebeauty.acmforever` |
| `versionCode` | 正整数，只有高于已安装版本才允许更新；本版为 22 |
| `versionName` | 展示版本，如本版 `0.2.8` |
| `apkUrl` | 真实、可下载的 HTTPS 安装包地址 |
| `sha256` | 实际 APK 的 64 位十六进制 SHA-256 |
| `sizeBytes` | 可选，实际字节数；填写后严格核对，不超过 150 MiB |
| `minSdk` | 最低 Android API，默认 26 |
| `notes` | 可选，更新说明，不超过 8000 字符 |

清单即使返回当前版本，也需字段完整。客户端验证清单、文件哈希、实际包名/版本及已安装签名。调试包与正式包应分渠道发布，签名不匹配时拒绝更新。未部署返回 404/405 时显示“无API接口”；断网、服务器错误和正常“已是最新版”分别处理。

本轮已实现客户端流程。服务器未发布清单或 APK 时，不能验收为线上更新可用；需要小组提供真实地址后完成端到端联调。
