## 登录与升级

记住密码需同时记住账号；自动登录同时开启前两项。关闭记住密码会关闭自动登录，关闭记住账号会关闭全部保存选项。只记住密码时填充表单，需要手动登录。

密码与持久会话由 Android Keystore AES-GCM 加密。密码绑定服务地址与账号，明文不进入 Activity 保存状态。自动登录先验证持久会话，过期后尝试保存的密码；断网或服务器异常不重放密码，也不删除有效密码。密码认证失败、退出、改密或取消保存会清理相应项。

同包名、同签名覆盖更新保留设置及可用凭据；卸载或清除应用数据会删除。旧版没有保存的密码不会凭空恢复。

## 缓存与错误

论坛、排行、题库、资料、训练等 JSON 读取按服务地址、会话和完整请求缓存。返回已读页面先显示缓存，再后台读取；不同平台、查询、页码分别缓存。成功空结果也缓存。页面部分 API 缺失时保留已成功区域及真实缺失状态。

JSON 采用进程内 LRU，最多 160 条、约 8 MB 字符预算；头像最多 64 张，PDF 最多 5 份且合计 64 MB。PDF 与 JSON 索引不承诺跨进程离线使用。退出或切换账号/服务器清除对应私有缓存；写入后失效相关缓存。

刷新开始 5 秒后仍未完成或失败，顶栏下显示红色“API连接失败”，未手动关闭前保持显示；只读请求在失败后每隔 5 秒继续重试。关闭提示不停止重连，连接成功显示绿色“重连成功”，3 秒后自动关闭；离开页面停止旧页面重试。写操作、缺接口与无权限等不会自动重试。有缓存时连接失败继续显示已有数据。首次无缓存显示“无网络”“无法连接服务器”等真实错误；缺接口、权限、空结果分别处理，不生成业务假数据。缓存不替代登录校验或权限验证。

点赞与话题收藏在服务端确认后只更新按钮状态/计数，保留滚动和评论输入，重复点击不会并发提交。

## 美工与实现边界

全套图标、默认头像、加载动画均原创重绘并加入猫娘元素。按钮去阴影，短弹窗统一主题，长内容全屏显示；参考素材移到仓库外本地素材库，未打包。说明见 [美工参考与实现](美工参考与实现-v0.2.3.md)。浏览器原型未同步，体验本版使用 APK。

API 仍复用网页后端。未增加或部署后端接口，缺少训练能力时显示“无API接口”。正式成员账号的写操作、各品牌实体手机通知与覆盖升级仍需实际设备验收；本地测试结果见 [安装说明](安装说明-v0.2.3.md)。
