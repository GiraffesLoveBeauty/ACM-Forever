已从官方 pkgs.tailscale.com 下载并安装 Windows amd64 客户端 1.104.1；安装包 Authenticode 状态 Valid，发布者 Tailscale Inc.。Windows Installer 返回 0，Tailscale 服务 Running，已打开客户端界面。检查时尚未确认本机在线或能看到目标服务器；需要用户完成登录、接受群内邀请并获得访问权限，之后再检查服务器连通性。

客户端安装没有修改服务器或原项目后端。

联调脚本：[check_live_api.py](../tools/check_live_api.py)。只保留 HTTP 状态、响应结构是否匹配和条数，不保存账号密码、Cookie、CSRF、响应正文或真实学生资料。默认直连，按实际需要可显式设置代理；HTTPS 证书始终校验，不自动跟随重定向。

在仓库根目录运行（域名需替换为负责人提供的地址）：

```powershell
python -B Android_APP/tools/check_live_api.py https://your-api-host.example
```

公开检查包含健康状态、未登录会话、论坛分类及三种排序、排行榜三个时间区间。默认不登录。需要验证本人接口时，用专用测试账号在本机设置进程环境变量 `ACM_APP_TEST_QQ`、`ACM_APP_TEST_PASSWORD`，再加 `--login`；仅登录、读取本人数据和退出，不改密、改资料或发帖。缺失接口区域显示红色“无API接口”；尚未部署的草案路径不作为正式路径调用。

结果保存到 `Android_APP/docs/live-api-result.json`，可使用 `--output` 指定 Android_APP 内的其他位置。该脚本结果不代替 Android 真机网络、安装及 APK 更新验证。
