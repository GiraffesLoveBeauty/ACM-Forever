## CI 与发布边界

远端已存在 `android-ci.yml` 和 `android-release.yml`。本轮保留正式签名配置，补清单测试、SDK 35 安装和实际 APK 元数据生成。正式工作流仅在发布非 prerelease 的 Release 时运行，长期签名密钥必须由维护者配置。

推 PR 分支不会触发 `sync-feat-to-server.yml`。整个 PR 合并 main 会因 feat/api 变更触发部署，发布前必须由运维确认可恢复备份、数据库增量迁移与生产验证。详细操作见 [android-app.md（当前工程与发布说明）](../../docs/android-app.md)。
