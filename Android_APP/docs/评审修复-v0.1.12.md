## 修复内容

| 级别 | 问题 | 修改 |
| --- | --- | --- |
| P1 | `URLEncoder.encode(String, Charset)` 需要 API 33，与 minSdk 26 不兼容 | 新增 `UrlEncoding.form`，使用 `encode(String, "UTF-8")`；统一替换 MainActivity 和 ApiClient 四处调用，路径段保留空格编码为 `%20` 的行为 |
| P2 | 不勾选自动登录时，Activity 重建会丢失 Cookie/CSRF | 由 `AcmApplication` 持有进程内 ApiClient 与 SessionVault；网络检查和会话回调不捕获 Activity。内存会话优先使用，只有新进程的自动登录才读取加密持久会话 |
| P2 | 服务端注销断网或返回 500 时，本地登录信息未清除 | ApiClient 在 finally 中清除 Cookie、CSRF、角色和改密状态；应用级注销回调清除会话密文、保存密码并关闭自动登录，账号与管理员入口共用。原生账号页切回登录表单，服务端注销未确认时单独说明 |

Activity 的 Bundle 只保存页面、筛选、分页、搜索和编辑状态，不保存 Cookie、CSRF 或密码。恢复与当前内存会话代次绑定；退出、换账号或变更服务地址后，旧页面的编辑状态不自动回填。Activity 销毁时作废其列表加载序号，避免旧回调更新已销毁界面。

不开启自动登录时，会话仅在当前进程内保留；进程结束后的冷启动仍需手动登录。已经失效的会话继续由服务端返回 401，并清除本地状态。
