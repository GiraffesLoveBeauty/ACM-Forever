## 已有要求继续保留

- 底部为主页、排名、中间加号发帖、题库、个人中心；顶部头像进入账号设置。
- 论坛分类和排序共用漏斗；重复点击不会叠加同一弹窗。
- 搜索先显示近 10 条历史与历史管理，再进入结果。
- 登录保留记住账号、记住密码、自动登录、小眼睛和登录等待；密码/持久会话使用 Keystore AES-GCM 加密。
- 排名排除所选平台合计为 0 的成员；保留与网页一致的时间范围、平台组合、排序及每页数量选择。
- 话题收藏/我的收藏、云端多草稿和自动保存、题面 PDF 翻页/缩放/适宽继续保留。
- 社团训练位于题库，含题单、按题讨论、错题本、补题、离线模板、打卡提醒；重管理功能继续由 Web 承担。
- 读取成功后缓存，返回先显示缓存再更新；缺接口、网络失败、空结果分别处理，无业务假数据。

## 边界

本轮没有部署或新增后端 API，没有使用正式成员账号执行训练/论坛写操作。新图标与个人中心仅更新 Android 原生客户端，浏览器原型仍为旧版，不作为本版界面验收入口。

本地参考库用于学习风格；当前 App 不包含从森空岛提取的路径、头像、图片或游戏角色。平台卡为原创文字标识，并非下载的官方 Logo。用户最后提出的“原创重绘”指令优先于此前直接复制图标的要求。

本机背景是外观文件，账号密码是加密凭据，均可随同签名覆盖更新保留；二者都不等同于可被清理的网络缓存。退出登录会清理凭据及相应私有网络缓存，保留本机背景外观。
