# ACMforever 网页与 App 功能对照目录

核对日期：2026-11-03。App 版本：v0.2.0（versionCode 14）。

范围：当前本地 `feat/web/src` 的 Vue 网页、Android 主构建实际包含的页面及本地接口实现。未拉取 GitHub 最新代码，未访问生产站点或验证线上接口；因此本文不是线上部署清单。当前有未提交的本地改动，新训练接口此前未部署，本次未重新核实服务器状态。

“有”表示当前源码有可到达入口及实现，不表示服务器正常、数据已采集或真机全流程已验收。旧静态网页、旧 App 管理源码、归档预览不计入当前功能。

## 四、两边都有，但细节不同

| 功能 | 网页实际行为 | App 实际行为 |
| --- | --- | --- |
| 登录保存 | 以浏览器 Cookie 和后端会话恢复为基础；登录表单无“自动登录”开关 | 仅记住账号；进程内保留会话，冷启动重新登录，不保存密码 |
| 论坛筛选 | 版块目录与排序分开展示 | 合并到漏斗弹窗 |
| 搜索 | 论坛、排行、题库各自输入和筛选 | 顶部进入搜索页，附本机历史和设置 |
| 发帖工具 | 完整 Markdown 工具栏、导入 .md | 简单编辑器，加粗/代码块/引用、预览 |
| 草稿 | 账号云端多草稿、自动保存 | 本机按服务地址及账号保存当前草稿；不与 Web 草稿同步 |
| 排行区间 | 7/30/90/365天及生涯 | 周/月/总；当前两边都没有“当日”可见选项 |
| 排行筛选 | 多平台组合、总数或平台数排序 | 全部或单个平台，按总数 |
| 排行分页 | 每页10/20/50/100人 | 固定20人、上下页；无页码输入及数量选择 |
| 题面阅读 | HTML、公式、样例；PDF.js 翻页缩放 | HTML/文本、公式、样例；未接入网页同等的 PDF 阅读界面 |
| 原题链接 | 独立原题按钮，在浏览器中打开 | 调用系统浏览器；有按钮仍写“在 App 内打开原题”，文案与实际行为不一致 |
| 个人资料入口 | 个人中心集中本人资料和设置 | 底部个人中心与顶部头像的账号设置分开 |
| CF 复盘状态 | 待处理、未通过、待补题、已解决、已复盘、忽略 | 未做、待补题、已解决、忽略；兼容旧状态映射 |
| 题单 | 管理员创建下发及看成员进度 | 成员查看和训练；不能创建、下发或查全员进度 |
| 审核 | 管理员实际审核帖子和举报 | 普通用户提交帖子与举报，无手机审核中心 |
| 新补题联动 | 本地新后端接管待补题状态，网页本身无计划界面 | 有待补题列表、间隔复习及到期提示 |

## 五、网页有，App 当前没有

1. 完整管理员后台及其10个管理入口；批量账号、CSV、重置他人密码、角色管理、成员资料维护等。
2. 题库初始化、采集、后台任务监控与取消。
3. CF 练习赛选题、查重、成员 AC/提交证据与复制候选。
4. 题单创建下发、全体成员完成情况查看。
5. 内容审核完整流程、举报处理。
6. 比赛播报配置、QQBot 管理员维护、字号偏好。
7. 深浅色切换、自助调色、主题方案、导入导出。
8. 话题收藏与“我的话题收藏”。
9. 云端多草稿、自动保存、Markdown 文件导入及丰富编辑工具。
10. 排行榜更多时间区间、多平台组合、平台排序及每页数量选择。
11. 站内 PDF 题面的完整翻页、缩放、适应宽度。
12. 为其他成员操作训练与复盘的管理员能力。

## 六、App 有，网页当前没有对应专门页面

1. 顶部搜索的最近10条历史、单条删除、开关和清空设置。
2. 明确分离的“个人中心 / 账号设置”导航结构。
3. 只记住账号的显式选项，以及独立登录等待界面。
4. 本机当前草稿保存模式（区别于网页云端草稿）。
5. 题目与讨论关联入口、错因标签及关键词筛选。帖子本身仍可在网页论坛阅读、评论、审核。
6. 私有错题本及个人错因笔记。
7. 补题计划与1/3/7天间隔复习界面。
8. 今日训练中的到期补题和连续/活跃天数摘要。
9. 八项离线模板的搜索、阅读和复制。
10. 训练打卡、目标、连续打卡天数。
11. Android 本地训练提醒、复习提醒、权限和关闭设置。

其中5–8及10的联网数据依赖后端；“App 有界面”不代表离线可用。离线模板是真正的本地业务能力。本机草稿虽本地保存，进入发帖页面仍受分类接口加载状态影响，不能认定断网时完整发帖编辑流程可用。
