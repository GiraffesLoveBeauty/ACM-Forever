## 安装步骤

1. 若已安装旧调试版，先保存需要的本机草稿，再卸载旧版。旧调试签名密钥已不在本机，新版使用新调试签名，不能直接覆盖安装；卸载会清除本机设置和草稿，不删除服务器账号或服务器业务数据。
2. 将此 APK 复制到手机，使用手机文件管理器打开；按系统提示允许该文件管理器安装应用，再确认安装。
3. 打开后登录自己的账号。访问当前默认服务仍需手机具备该 Tailscale 内网的访问权限。
4. 模板可离线查看。需要通知时在训练打卡页主动设置提醒时间，并授予系统通知权限。
