# ACMforever v0.2.1 美工参考与实现

日期：2026-11-03。设计参考与本地实现记录。

## 来源与方法

参考包来自[森空岛官方下载页](https://www.skland.com/download)的公开配置。包名 `com.hypergryph.skland`，版本 `2.3.0`，SHA-256：`C738C18A77C3865D97809D676DFC46477716F2472474828C20AE56E94DF57964`。

使用 Android SDK 的 `aapt2 dump resources/xmltree` 直接读取编译资源表与布局树，并查看 APK 文件目录。可分析 XML、矢量图、图片、字体和动画。部分页面为 Compose，部分功能包含编译后的 JS 字节码，因此不能完整还原原始源码；不把局部布局树当作完整页面。

官方包在独立 Android 15 x86_64 模拟器安装成功，但启动发生 ARM64 原生库 `SIGILL`，调用栈涉及 `libmmkv.so`。这只能确认当前环境启动失败，不能判断是否因反爬或模拟器检测。本轮未看到完整内部运行页面，未绕过登录或防护。

| 字体目录 | 不同字重与数字字体 | 系统 sans 与分级字重，不打包第三方字体 |

## 代码位置

- `MainActivity`：标题区、论坛卡片、筛选、账号菜单、导航。
- `CommunityIcon`：几何图标，避免字符加号的基线位移。
- `MobileStyle`：统一训练与阅读页颜色、圆角、按钮反馈和 dp 间距。
- `ClubActivity`：训练标题、白卡、模板与训练菜单。
- `PdfActivity`：工具区和阅读状态，题面保持 PDF 原样。
- `reader/index.html`：同步 HTML/Markdown 阅读配色。

使用自己的图标、布局代码、配色组合与系统字体。官方包、解析文件和原素材留在仓库之外的本地参考目录，不进入源码或交付 APK。本轮参考不只依赖截图；截图用来检查 ACMforever 的实际呈现。
