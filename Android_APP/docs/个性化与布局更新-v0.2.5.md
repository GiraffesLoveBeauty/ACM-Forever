# ACMforever 个性化与布局更新 v0.2.5

版本：0.2.5，versionCode 19。本轮仅修改 Android_APP 内文件，只在本机构建，不提交、推送或部署。

## 页面目录

```text
顶部头像 → 账号设置（首页菜单行无右侧箭头）
└── 个性化设置
    ├── 背景选择
    │   ├── 选择本机图片：复制至应用私有目录，不上传
    │   │   └── 透明度：六档滑条，0/20/40/60/80/100%，默认40%，界面不显示数字
    │   ├── 使用纯色背景
    │   └── 使用渐变背景：上半为选定颜色，下半渐变至白色
    │       └── 与主题同色 / 自定义：支持点击和左右滑动切换
    │           └── 自定义：预设纯色圆点 / 彩虹圆点 → 调色盘 → 应用颜色
    └── 主题选择
        ├── ACMForever：预设纯色圆点 / 调色盘
        └── 主题库：本地转换网页五套预设，每套有浅色 / 深色
```

背景是主导航、账号设置、搜索、发帖、题目、训练和 PDF 阅读容器的全屏底图。卡片和正文保留主题底色与文字对比度，PDF 题面本身保留原文档颜色。初始为白色背景；切换背景类型不删除已经选择的本机图片。三种背景按钮当前项为黄绿色，其他为白色。

## 插画和图标

- 头像与加载插画复用用户提供的原图，按区域遮罩换色：头发/眼睛一组，服装一组，蝴蝶结/装饰一组。三组采用与主题主色协调的配色，保留原图明暗。肤色、耳朵、领子、袖口花纹及电脑不换色。
- 首页标题旁恢复为代码尖括号、斜线与猫娘剪影组合，按等比绘制。加载插画和剪影也按原宽高比缩放。
- 导航/操作图标使用加粗线条。平台页新增 ALL 猫娘剪影选项，平台图标使用同底色圆形外框；切换只更新同一个详情区域。累计过题数与最近 AC 独立分框，逐题记录仍仅本人可见。
- App 启动器图标使用猫娘剪影。系统桌面图标使用随包的固定底色；应用内部图标、头像和插画跟随当前主题。

## 发帖与反馈

- 发帖页格式工具和草稿操作按可用宽度自动换行，移除横向滚动容器。按钮字号缩小，最小高度 44dp，横向和纵向均留 8dp 间距，保留全部编辑操作。
- 账号设置首页各菜单行删除右侧箭头，整行仍可点击，返回/翻页等功能按钮不受影响。
- API 超时警告为 10 秒；网络类错误持续重试。红色“API连接失败”在恢复前持续显示，可手动关闭，关闭不停止重试。恢复后绿色“重连成功”显示 3 秒自动关闭。缺失 API 与空内容继续按真实状态展示。
- 点赞和评论沿用上一版原地反馈、失败红条及编辑保留逻辑。

## 本地数据与验证方式

设置使用本机 SharedPreferences，背景文件保存在应用私有目录，不经过业务 API。覆盖安装保留这些数据，卸载或清数据会删除。沿用 v0.2.4 的本地调试签名，便于覆盖更新。

构建使用 JDK 17、SDK/Build Tools 35 和 Gradle 8.9。当前 Windows 中文路径下，Gradle JVM 测试可能找不到已编译的测试类；验证使用本机临时英文路径的源码副本。测试包内的 `.invalid` 接口响应只用于隔离界面验证，不进入交付 APK。验证结果见本版安装说明。
