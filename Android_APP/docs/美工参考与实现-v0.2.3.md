# ACMforever v0.2.3 美工参考与实现

2026-11-03。沿用浅灰底、白卡、深色文字、亮绿强调，参考用户森空岛截图的信息层级；素材由本项目原创绘制。

## 原创资源

- `AppIcons.java`：24 单位 Canvas 图标。功能轮廓保持清晰，每枚加入猫耳或猫娘剪影；导航分别为气泡、奖杯、加号、书页、猫娘头像。
- `avatar_catgirl.xml`：原创 Q 版猫娘默认头像，含猫耳、两侧头发、水手领和发饰。
- `CodingCatView.java`：原创猫娘敲代码循环动画，本地实时绘制，无视频、GIF 或外部素材下载。视图不可见时停止重绘。
- `ic_launcher_foreground.xml`、`ic_cat_notification.xml`：启动与通知猫娘剪影。
- `CommunityArtwork.java`：带猫娘角标的代码装饰。
- `PlatformMark.java`：CF、洛谷、AtC、牛客、CJLU 的原创文字标识与猫娘角标，未冒充官方 Logo。

图标通过尺寸、线宽和基本轮廓保证识别，触摸目标保持约 44–48dp；眼睛、返回、关闭、缩放等保留无障碍说明。普通系统输入控件继续使用系统交互。

## 页面与弹窗

个人中心改为身份区、真实统计、本人快捷菜单、横向平台卡及公开话题。逐题 AC 记录仅自己可见，其他成员公开范围仍为平台汇总。

短弹窗为白色圆角、统一标题与关闭入口、亮绿主要操作，按钮无阴影。列表、模板与详情使用带返回栏的全屏子页。保留已有单窗口检测。

## 本机背景

设置入口：头像 → 账号设置 → 个人中心背景。未登录时也可设置。默认纯白，可选择图片或淡色渐变。图片经尺寸限制、EXIF 方向处理与 JPEG 压缩后复制到应用私有文件；上部取色与渐变下半白只用于本机显示，不触发任何 API 上传。

文件与外观设置跨 App 重开保留，同签名覆盖安装继续保留；卸载或清除应用数据会删除。原照片在外部相册移动/删除不影响副本。

## 本地参考素材库

`E:\爱臭美工程\森空岛素材库\index.html`：离线打开即可搜索、分类、翻页预览。`manifest.json` 记录源 APK SHA-256、资源名、路径、原始文件 SHA-256、失败记录；`original/` 保留原始字节，`preview/` 为近似 SVG/PNG 预览，`legacy-reference/` 保留上一版来源记录。

v0.2.2 直接提取的 `sk_*` 资源已从 Android 资源目录移出。原提取工具的写入 App 入口已禁用；新 `build_reference_library.py` 只生成本地参考库。参考库位于仓库之外，不进入 APK。本版未使用参考图标路径制作原创图标。
