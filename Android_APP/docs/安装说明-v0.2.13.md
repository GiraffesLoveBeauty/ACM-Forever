# ACMforever v0.2.13 本地调试包

日期：2026-11-04。版本 `0.2.13` / `versionCode 27`，包名 `com.giraffeslovebeauty.acmforever`。最低 Android 8.0（API 26），target SDK 35。

## 本次更新日志

- “检查更新”页面下方新增“更新日志与说明”，按版本从新到旧列出，并标明当前安装版本。本次 0.2.13 已包含在内。
- 每个版本可进入独立详情查看变更及使用说明；连续点击只保留一个窗口，返回后保留列表滚动位置。
- 记录随 APK 保存，不需要网络或登录；检查服务器更新失败时仍可查看本地日志。
- 详情使用跟随模块透明度的主题阅读卡片；全屏详情与主页面共用系统栏底色和边距处理，避免自定义图片延伸到时间区域。
- 构建增加日志与当前版本一致性检查，避免新包遗漏本版说明。
- 修复排行榜请求绕过移动端公开身份接口的问题；服务器支持时保留公开成员 ID，点击榜单成员打开资料和已发布话题。旧服务器回退普通排行榜，兼容零 AC 过滤的补充分页也沿用选定接口。
- 修复论坛列表、详情绕过移动作者身份接口的问题；按能力读取公开作者 ID，保留通知评论定位，点击作者进入真实成员资料和话题后可返回。
- 修复多编辑页切换云端草稿的串写：编辑 A → 云端草稿选择 B → 返回原编辑页时，标题、正文、分类与草稿 ID 一起同步为当前 B。旧 A 控件、迟到保存和导入不能写入 B；旧页面停止时也不能取消 B 的自动保存。
- Wiki 关联练习的 `/problem.html?platform=…&problem_id=…` 相对链接进入原生题面与样例，返回原 Wiki 文章。缺少平台或题号时明确报错，真正的外链仍要求 HTTPS。
- 选择 Markdown 文件期间，编辑页重建会在同一会话下恢复导入时的账号/草稿代次。账号或草稿真正切换时继续拒绝迟到结果，不把新页面自动绑定为旧导入目标。
- 页面重建不再重复调用共享客户端的 `setBaseUrl()`，避免在慢请求或云端自动保存期间等待网络锁。服务地址和无效配置清理统一由 Application 启动时处理，保留原有会话与草稿串行保护。

App 在进程内共用当前草稿。进入草稿列表前会先保存 A，选择 B 后返回旧编辑页继续编辑的是 B；不会只换草稿 ID 而保留 A 的正文。保存失败时保留输入并提示，不静默切换。

共包含 27 个版本条目：0.2.0～0.2.13、0.1.0～0.1.12。有原始说明的版本按安装说明和既有文档整理；0.1.0～0.1.9 仅有旧包存档，明确标出缺少逐项变更记录，不推测补写。未核实日期留空。
