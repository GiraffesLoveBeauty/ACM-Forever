## 三、顶部导航与常用工具

### 3.1 头像与搜索栏

- **已实现**：顶部左侧头像进入账号设置；不会直接切换到底部个人中心。
- 顶部中间搜索栏按当前栏目搜索：论坛话题、排行榜公开昵称、题库题名/题号/标签。
- 点击搜索栏先进入独立搜索界面，提交关键词后再进入结果页。
- 最近 10 条搜索以可点击方框展示，去重并按最近使用排序；无预置搜索内容。
- 点击历史条目可直接搜索。
- “历史记录”支持查看及删除单条记录。
- “历史记录设置”支持停止记录和清空记录；历史仅保存在当前设备。

### 3.2 顶部小“＋”工具

- **已实现**：右上角使用矢量加号图标，与头像、搜索栏并排，打开常用工具菜单。
- 菜单提供“扫一扫”和“检查更新”。
- **部分实现**：扫一扫目前接受粘贴普通 HTTPS 网页链接，展示域名和完整链接，确认后在 App 内打开。
- **未实现**：摄像头扫码、二维码图像识别及官方站内二维码跳转协议。

## 四、登录与会话

### 4.1 登录流程

- **已实现**：用户名 / QQ 与密码登录，验证服务端会话后才进入登录状态。
- 点击登录后进入独立等待界面，显示加载动画；慢请求提示检查网络和 Tailscale。
- 登录成功返回原操作目标；初始密码需要先修改。
- 登录失败显示具体原因，保留账号并清空密码，允许重试。

### 4.2 三个登录选项

| 选项 | 功能与限制 |
| --- | --- |
| 记住我 | 记住账号，方便下次填写 |
| 保存密码 | 可选；Android 使用设备 Keystore 加密保存，绑定服务器及账号，仅成功登录后保存 |
| 自动登录 | 可选；保存加密会话，下次冷启动联网验证会话；过期或失效后重新登录 |

- 改账号时清空密码输入；取消保存密码、退出登录或成功修改密码后删除保存密码。
- 自动会话保存期限最多 30 日，并受 Cookie 有效期限制；CSRF 不持久化。
- 不勾选自动登录时，仍在当前 App 进程内保留会话；冷启动不自动恢复。
- Application 持有会话，Activity 重建可恢复当前登录与相关页面状态；相关真机验收见第十七节。
- 退出时，即使远端注销因断网或服务器错误失败，也清除本机 Cookie、会话、保存密码及自动登录标志，提示远端注销未确认。
- 不提供自主注册和找回密码流程；账号发放与重置由管理员处理。

## 五、主页与论坛

### 5.1 列表与筛选

- **已实现**：社区话题列表、分类名称、标题、摘要、作者头像/名称、评论数、点赞数及分页。
- “社区话题”同高度右侧提供漏斗按钮，分类与排序合并在一个面板内。
- 分类读取服务器配置，提供“全部”及服务器实际返回的分类，不写死业务数据。
- 排序：最新、热门、待回答。
- 支持关键词检索；切换筛选重新加载结果。
- 点击话题打开详情；点击作者头像或名称进入公开主页，前提是服务端提供公开身份。

### 5.2 详情与互动

- **已实现**：标题、分类、作者、时间、阅读数及正文阅读。
- 正文支持 Markdown、代码块、公式、表格与安全处理后的内容；正文链接可交应用内浏览页打开。
- 支持点赞/取消点赞、收藏/取消收藏和举报；写操作需要登录。
- 举报理由校验为 3–500 字。
- 支持评论及一层回复；可取消当前回复目标。
- 评论校验为 2–5000 字，展示作者、时间、正文和回复关系。
- 详情展示服务器返回的已发布评论；不伪造互动数量或提交成功。

## 六、发布话题与草稿

- **已实现**：底部中央大“＋”直达简单发帖编辑页，与顶部工具加号分工不同。
- 编辑字段：服务器分类、标题、Markdown 正文。
- 标题长度 4–120 字；正文长度 5–20000 字。
- 格式工具：加粗、代码块、引用；可在提交前本地预览正文和公式。
- 分类加载成功后可先编辑；保存或提交前要求登录，并保留本次编辑以便登录后返回。
- 云端草稿支持新建保存、再次保存、从草稿列表打开、继续编辑和确认删除。
- 显示草稿保存状态；失败时保留当前编辑内容，防止异步保存覆盖更新的编辑。
- 离开未保存编辑时提供提醒及保存选择。
- 提交时先保存草稿，再提交审核；通过后才公开出现在主页。
- **限制**：未主动保存的内容不保证在进程结束后恢复；没有离线发帖队列或自动上传功能。未实现附件上传编辑器。

## 七、排行榜

- **已实现**：名次、头像、公开昵称/身份、各平台通过题数和合计。
- 时间区间：当日、近 7 日、近 30 日、近 90 日、近 1 年、生涯。
- 平台多选：Codeforces、洛谷、AtCoder、牛客、校 OJ；可选择总 AC 或分平台排序。
- 支持公开昵称等关键词搜索，点击成员进入公开主页。
- 排行榜过滤所选平台合计 0 AC 的成员。
- **依赖后端支持**：当日按北京时间当天 00:00 至次日 00:00 统计；不使用“最近 24 小时”代替。当服务器不支持此统计能力时显示“无API接口”。
- 旧服务器普通周期会由客户端读取公开分页，过滤零 AC 后重新分页；成员较多时需要更多请求。

分页栏从左到右排列：

```text
上一页 ｜ 第[可输入页码]页（共 X 页） ｜ 一页[数量]项 ｜ 下一页
```

- 每页数量提供 **5、10、20、100** 四档。
- 输入页码后通过回车或完成编辑跳转。
- 空值、非整数、负数、0、溢出、超过总页数等非法输入回到第一页。
- 更换筛选或每页数量回到第一页；边界禁用上一页/下一页。
- 空榜仍保留分页栏，按共 1 页显示。

## 八、题库与题目详情

- **已实现**：本人题库需要登录，未登录时提示并引导进入账号设置，成功后可返回。
- 平台筛选：全部、Codeforces、洛谷、AtCoder、牛客、校 OJ。
- 支持关键词/标签筛选、全部/收藏切换、题目总数和分页。
- 列表展示题名或题号、平台、难度及标签。
- 支持收藏和取消收藏。
- 题目详情展示已采集题面、公式、样例输入和样例输出，可复制样例。
- 如果服务器只有题目目录、没有题面，明确提示尚未采集，提供原题外链。
- 原题 HTTPS 链接可在 App 内打开。
- **限制**：客户端不内置题库数据，不直接在手机端执行代码判题，也没有本地判题器。

## 九、个人中心与他人公开主页

### 9.1 公开内容

- **已实现界面**：头像、用户名、公开身份、座右铭、各平台通过题数、合计和已发布论坛话题。
- 底部个人中心展示本人公开主页；论坛或排名中的成员入口展示他人公开主页。
- 做题信息仅公开各平台通过题数，不公开逐题 AC 历史、私密绑定、草稿或待审核内容。
- 点击已发布话题可进入详情。

### 9.2 数据与可用性

- 本人通过题数复用现有个人资料数据；本人已发布话题复用“我的话题”并筛选已发布状态，受最近 100 条上限限制。
- **依赖后端支持**：稳定公开成员身份、他人完整资料/话题、座右铭读取和修改。
- 座右铭、统计和帖子区域分别处理失败；单个区域失败不会直接遮住所有其他可用内容。
- 缺失能力显示红色“无API接口”，不补造用户名、题数或帖子。

## 十二、管理员管理中心

### 12.1 入口、权限与公共操作

- **已实现**：顶部头像 → 账号设置 → 管理员栏 → 管理后台。
- 进入时再次验证服务端会话与角色；普通成员不能加载管理模块。
- APK 内使用本地打包的管理界面，复用仓库现有管理模块及登录会话。
- 模块下拉选择、横排模块导航、刷新、返回账号设置、退出账号及外观编辑。
- 手机表单、横向表格、加载态、错误态和重试。
- 本地可信管理页通过受限原生桥请求后端；不向远程网页开放该桥，不向 JavaScript 导出密码或 Cookie。
- Root、普通管理员及 QQBot 管理权限分别以服务器校验结果为准。

### 12.2 九个管理模块

| 模块 | 已接入的主要功能 |
| --- | --- |
| 成员账号 | 搜索已有成员、批量选择并发放账号、创建账号、查看发放结果、复制账密、导出 CSV、重发临时密码、设置初始密码、启用/停用、按权限调整角色；离开发放结果前提醒保存 |
| 成员资料 | 搜索和分页查看成员，进入详情，维护昵称/身份及 OJ 绑定，查看平台统计和最近 AC 摘要 |
| 训练管理 | 针对成员设置平台、标签/难度等条件，生成训练推荐并查看挑战历史 |
| 题库管理 | 题目采集与后台任务相关操作，按成员/平台/关键词/收藏筛选题目，管理收藏及题目打开入口 |
| CF 练习赛选题 | 选择参与成员与排除成员、刷新概况、同步数据；按日期/标签/关键词查看近期 AC，按题目汇总或按成员展开；批量题号/CF 链接或整场比赛查重，选择排除所有提交或仅排除 AC，查看成员证据，复制所选题号/链接 |
| 赛事复盘 | 按成员 QQ、比赛 ID 查询题目并管理逐题复盘状态 |

## 十三、应用内网页

- **已实现**：对粘贴链接、正文链接及原题链接，先展示域名和完整 URL，确认后打开应用内浏览页。
- 接受普通 HTTPS 链接；拒绝不安全协议及不符合规则的地址。
- 浏览页支持返回、刷新、显示当前地址及交外部浏览器打开。
- 支持网页历史返回；无历史时返回 App。

## 十四、检查更新与安装

**状态：客户端下载、校验及交系统安装器的流程已实现；正式发布服务待接入，完整链路待真机验证。**

1. 从顶部工具或账号设置点击“检查更新”。
2. 请求版本清单，验证清单格式、包名、版本及 HTTPS 下载地址。
3. 清单成功返回且没有更高版本，才显示“已是最新版”。
4. 有新版本时展示说明和“更新 X.X 版本”按钮。
5. 用户确认后由系统下载，进度在系统通知中查看。
6. 下载后校验 SHA-256、实际包名、versionCode 及签名，校验失败停止安装。
7. 通过校验后请求系统安装器；侧载需允许安装未知应用，安装仍由用户确认。

- 重复检查、提示及下载有防重保护。
- 未配置发布服务时显示“无API接口”；断网显示“无网络”，不会假报“已是最新版”。
- 正式更新包应保持包名与签名一致，versionCode 递增，才能覆盖安装。
- 当前默认版本清单地址为空；已有旧配置可以保留。当前调试包不等于已接入自有服务器发布。
- 浏览器预览仅提供 APK 下载，不能代替 Android 原生校验和系统安装流程。

## 十五、通用交互与错误提示

### 15.1 防重复与页面状态

- **已实现**：统一弹窗协调，同类窗口已打开时保留原窗口和输入；切换弹窗时先处理旧窗口。
- 异步入口有加载/忙碌状态，避免排队点击造成多个窗口重叠或重复写请求。
- 筛选、资料、确认、预览、错误、扫码入口、更新及管理员原生提示使用相应保护。
- 页面切换后忽略过时请求结果；Activity 重建恢复部分导航、筛选、搜索和编辑状态，并绑定当前会话。
- 凭据不写入页面恢复 Bundle，应用禁用系统备份。

### 15.2 数据状态

- 加载状态、有内容、有效空结果、错误状态分别展示。
- 红色错误方框保留原内容区域面积，并在适用位置提供重试。
- 缺失接口：**无API接口**。
- 断网：**无网络**。
- 其他原因按实际情况显示：未配置服务器、未登录或登录已失效、无访问权限、请修改初始密码、请求过于频繁、请求超时、无法连接服务器、服务器异常、内容不存在、功能已下线、安全连接失败、数据格式异常或服务器返回的业务校验错误。
- 服务端成功返回空列表时显示“暂无内容”等提示，不当成接口故障。
- 不使用演示成员、虚构题数、伪造帖子或虚假成功；不在产品中展示接口记录清单。
