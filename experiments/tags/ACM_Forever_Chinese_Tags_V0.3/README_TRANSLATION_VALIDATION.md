# 翻译占位符保护与离线回归

## 当前自动流程：不再进行内容一致性拦截（2026-11-04）

按用户要求，自动执行器和翻译入口改用 `parse_translation()`：只解析 JSON 题名和正文、恢复已知占位符，不再检查公式/变量顺序、占位符出现次数、数字、段落完整性、Markdown 结构或中文覆盖率。正常匹配的段落保留原分隔符；段落 ID 不匹配时仅展示模型实际返回的段落，不用原文静默补齐。未知占位符按模型原样保留。

无法解析或题名/正文为空的响应仍不能展示。网页 HTML 清洗、题目身份与正文绑定、人工覆盖保护、任务锁及不确定状态禁止重试继续生效；算法标签的合法 ID 检查没有移除。图片题的输入完整性预检独立于译文内容校验，本次没有取消。

新结果记录 `translation_validation_mode=parse_only`，页面明确显示未进行本地内容一致性校验、未人工确认。请求提示词、输出 Schema、模型参数及请求版本保持原样，避免使已付费结果失效或触发重复处理。未改写旧结果、请求状态或原始响应，也不会自动重新处理历史失败任务。

`validate_translation()` 只保留给显式的旧响应离线审计工具及历史回归，不再由自动 API 处理路径调用。下面记录的是此前的严格审计规则，不能作为当前自动流程的说明。

本次修复针对一次真实单题响应暴露的问题：英文冠词 `a` 被误当变量，以及正常中文语序被要求与英文变量顺序完全一致。修复和测试均为离线操作，未重新发送请求。

## translation-2 的规则

- 公式、复合表达式、代码块（含 CRLF 换行）、行内代码、链接和图片整体保护；还原时直接使用原始字符串，不由模型重新生成。
- 单字母变量使用独立占位符。容易与英文混淆的 `a`、`A`、`I` 需要局部符号证据，例如 `integer a`、`Print a.`、`a is even`、`A and B` 或明确的数学/代码标记。`a train`、`A train`、`Print a single integer`、`I have` 不作为变量保护。
- 这是保守的启发式识别，不是完整语法分析。歧义变量优先在源数据中使用 `$a$`、`$I$` 等数学标记；不能据此宣称已经验证译文语义正确。
- 请求显式提供 `movable_tokens` 列表，告知模型哪些单变量占位符可以重排；其他占位符均为固定保护内容。单变量只允许在同一段、同一行、相同固定保护边界之间重排，以适应中文语序。不得跨行、跨段或跨越公式、代码、样例及链接。无法判定是否安全的重排拒绝并交由复核。
- 每段逐一核对占位符及出现次数；缺失、重复、未知或损坏的占位符均拒绝。固定保护内容的顺序不得变化，公式内部与样例字节不得变化。
- 段落 ID、顺序、数字、Markdown 标题/列表结构和中文输出检查继续保留。输出题名不允许夹带占位符；输入中出现保留前缀时在发送前拒绝。
- 不带新可移动变量元数据的旧预处理对象继续严格校验，不自动获得重排权限。

## 版本和历史请求

翻译策略版本递增为 `translation-2`，提示词说明允许的重排范围。输出 JSON Schema、模型及 API 参数未改变。标签策略独立，不因本次翻译修复而重新标注。

新策略会改变翻译任务身份和请求指纹。旧策略的结果由规划器标记复核；已有 `blocked` / `uncertain` 历史仍阻断同题翻译，不因版本升级自动重发。不删除或改写旧缓存、原始响应、任务记录及人工历史，也不将旧占位符编号直接套用新预处理结果。

上一次失败的真实响应仅保留为审计证据，未激活为有效译文。修复后的行为通过合成数据和隔离 Mock 验证，不等同于再次通过真实翻译验收。
